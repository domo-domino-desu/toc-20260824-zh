\begin{ans}{1.2.6}
(From \autocite{blass}.)
The first benefit that we get from this thesis is that it lets us
connect formal mathematical theorems to real-world issues of computability.
For example, the theorem that the word problem for groups is Turing-undecidable
has the real-world interpretation that no algorithm can solve all instance of
the word problem.

The second benefit is in mathematics itself, specifically in computability
theory.
Published proofs that something is Turing-computable almost never proceed by
exhibiting a Turing-machine program, or indeed a program in any actual
computing language.
Sometimes, if the matter is simple enough, they provide some sort of
pseudo-code.
Most often, though, they merely give an informal description of an algorithm.
It is left to the reader to see that this actually does give an algorithm
(in the intuitive sense) and therefore, by the Church-Turing thesis, could be
simulated by a Turing machine.
The usual situation is that, although experts in Turing-machine programming
would (if they existed) be able to routinely convert the intuitive algorithm
into a Turing machine program, the program would be too large and
complicated to be worth writing down.
\end{ans}

\begin{ans}{1.3.19}
\autocite{Davis}
Suppose that if two functions $\map{f,\hat{f}}{\N^{n+1}}{\N}$ both
satisfy \cref{def:PrimitiveRecursion}.
We will show that for all $\sequence{x_0,\ldots,x_{n-1},y}\in\N^{n+1}$
the two are equal $f(x_0,\ldots,x_{n-1},y)=\hat{f}(x_0,\ldots,x_{n-1},y)$,
by induction on~$y$.

For the base step,
they are equal when $y=0$ because they both equal $g(x_0,\ldots,x_{n-1})$.
For the inductive step,
suppose that they are equal for $y=0$, \ldots, $y=k$ and consider
the $y=k+1$ case.
\begin{align*}
  f(x_0,\ldots,x_{n-1},k+1)
  &=g(f(x_0,\ldots,x_{n-1},k),\,x_0,\ldots,x_{n-1},\,k)
  &=g(\hat{f}(x_0,\ldots,x_{n-1},k),\,x_0,\ldots,x_{n-1},\,k)
   =\hat{f}(x_0,\ldots,x_{n-1},k+1)
\end{align*}
The second equality follows from the induction hypothesis.

\begin{ans}{2.1.47}
\begin{exparts}
\item   Assume that $\map{f}{D}{C}$ is one-to-one.
  We will do induction on the number of elements in~$D$.
  The base step is that~$\sizeof{D}=0$.
  The codomain cannot have fewer elements than this
  so~$\sizeof{C} \geq \sizeof{D}$ holds in this case.

  For the inductive step assume that the statement is true when
  $\sizeof{D}=0$,
  \ldots, $\sizeof{D}=k$ and let~$D$ be a set with~$\sizeof{D}=k+1$.
  Pick some $d\in D$ and consider
  $\hat{D}=D-\set{d}$ (because this is the $k+1$ case, there is at least
  one such element).
  The inductive hypothesis applies to $\hat{D}$ so that
  the number of elements in the range of the restriction map
  $\map{\hat{f}}{\hat{D}}{\range(\hat{f})}$
  is at least as great as the number of elements in the domain of that map
  $\sizeof{\range(\hat{f})} \geq \sizeof{\hat{D}}$.

  Now extend to~$D$ and the map~$\map{f}{D}{C}$.
  The set~$D$ has one element more than the set~$\hat{D}$.
  Because~$f$ is one-to-one, the value~$f(d)$ is not in
  the range of the restriction map~$\range(\hat{f})$.
  Thus $\range(f)$ is one element larger than
  $\sizeof{\range(\hat{f})}$.
  Therefore $\sizeof{C} \geq \sizeof{D}$.

\item   Assume that $\map{f}{D}{C}$ is onto.
  We do induction on the number of elements in
  the domain~$D$.
  The base step is that~$D$ has no elements, so $D=\emptyset$.
  The only function with an empty domain is the function whose graph is
  empty.
  This function is onto so the codomain~$C$ is also empty
  (otherwise there would be an element of the codomain with no inverse
  image).

  For the inductive step assume that the statement is true when $\sizeof{D}=0$,
  $\sizeof{D}=1$, \ldots, $\sizeof{D}=k$ and consider
  the~$\sizeof{D}=k+1$ case.
  Pick some $d_0\in D$ and consider
  $\hat{D}=D-\set{d_0}$ (because this is the $k+1$ case there is at least
  one such element in~$D$).

  There are two cases:
  whether the codomain element $f(d_0)$ is also the image of another domain
  element, some $d\in\hat{D}$, or else it is not.
  In the first case the restriction $\hat{f}$ is onto
  and so the inductive hypothesis applies, giving that
  $\sizeof{C}\leq \sizeof{\hat{D}}<\sizeof{D}$.

  In the other case, that $d_0$ is the only element of~$D$ associated
  by~$f$ with the codomain element~$f(d_0)$, let $\hat{C}=C-\set{f(d_0)}$.

One direction is that if a string~$\sigma\in\kleenestar{\B}$
is generated by the grammar then it is a palindrome $\sigma=\reversal{\sigma}$.
We do induction on the grammar's structure.
The basis step is that the string is either empty $\sigma=\varepsilon$,
or of length one~$\sigma=\str{0}$ or $\sigma=\str{1}$.
All three cases are evidentally palindromes.
For the inductive step we assume the length of the
string~$\lh{\sigma}$ is greater than one and that the statement is true for all
shorter strings, all~$\tau\in\kleenestar{\B}$ with $\lh{\tau}<\lh{\sigma}$.
In the case that $\sigma=\str{0}\tau\str{0}$, the string~$\sigma$ is a
palindrome by the inductive hypothesis that $\tau$ is a palindrome.
The case that $\sigma=\str{1}\tau\str{1}$ is similar.

The other direction is that if the string is a palindrome
$\sigma=\reversal{\sigma}$ then it is generated by the grammar.
We can use induction on the length~$\lh{\sigma}$.
If the length of $\sigma\in\kleenestar{\B}$ is~$0$ then the string
is empty, $\sigma=\varepsilon$.
In this case it is a palindrome and is also derived from the grammar since
\mbox{P \produces{} $\varepsilon$} is one of the listed production rules.
If the length of $\sigma$ is~$1$ then either $\sigma=\str{0}$ or
$\sigma=\str{1}$, and these two are both palindromes and also derived from
the grammar.
Finally, assume that $\lh{\sigma}>1$ and that the statement is true for all
strings $\tau\in\kleenestar{\B}$ of length less than~$\sigma$.
There are two cases.
If $\sigma$'s first character is~$0$ then because $\sigma$ is a palindrome
it has the form $\sigma=\str{0}\tau\str{0}$, where $\tau$ is a palindrome.
The induction hypothesis applies to give that $\tau$ is derived from the
grammar.
But then so is $\sigma$, using the production \mbox{P \produces{} \str{0}P\str{0}}.
The case that $\sigma$'s first character is~$\str{1}$ works the same way.
\end{ans}
