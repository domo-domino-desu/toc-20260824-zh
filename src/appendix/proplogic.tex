\section{Propositional logic}\label{sec:PropLogic}\index{Propositional logic|(}\thispagestyle{empty}

A \definend{proposition} is a statement that has a Boolean value,
that is, it is either true or false, which we write as $\true$ 
or~$\false\!$.\,\footnote{%
  In some contexts the tradition is to write $1$ where we write~\protect\true{} 
  and $0$ for~\protect\false\!.}
For instance, `$7$ is odd' and `$8^2-1=127$' are propositions,
with values $T$ and~$F\!$. 
In contrast, `$x$ is a perfect square' is not a proposition because for some 
$x$'s it is~$T$ while for others it is~\false\!.

We can operate on propositions, 
as with `it is not the case that $8^2-1=127$' 
or `$7$ is odd and $7$ is prime'.
The \definend{truth tables}\index{truth table} 
below define the behavior of the operations
\definend{not} (also called \definend{negation}),\index{logical operator!not@not $\neg$}\index{negation operator@negation operator $\neg$}
\definend{and} (also called \definend{conjunction}),\index{logical operator!and@and $\wedge$}\index{conjunction operator@conjunction operator $\wedge$}
and \definend{or} (also called \definend{disjunction}).\index{logical operator!or@or $\vee$}\index{disjunction operator@disjunction operator $\vee$}
\begin{center}\small % \vspace{0.5ex}
  \begin{tabular}[t]{c|c}
    \multicolumn{1}{c}{\ }    
        &\multicolumn{1}{c}{\tabulartext{not} $P$}  \\[-0.25ex]
    \multicolumn{1}{c}{$P$}      
        &\multicolumn{1}{c}{$\neg P$}  \\
    \hline
       $\false$  &$\true$  \\
       $\true$   &$\false$
  \end{tabular}
  \qquad
  \begin{tabular}[t]{cc|cc}
    \multicolumn{1}{c}{\ }    
        &\multicolumn{1}{c}{\ }    
        &\multicolumn{1}{c}{$P$ \tabulartext{and} $Q$}  
        &\multicolumn{1}{c}{$P$ \tabulartext{or} $Q$}  \\[-0.25ex]
    \multicolumn{1}{c}{$P$}      
        &\multicolumn{1}{c}{$Q$}      
        &\multicolumn{1}{c}{$P\wedge Q$}  
        &\multicolumn{1}{c}{$P\vee Q$}  \\

Thus we can determine the value of the conjunction `$7$ is odd and $8$ is prime'
in the right-hand table.
% Let `$7$ is odd' be $P$, and `$8$ is prime' be $Q$.
The \true-\false{} row in the $P\wedge Q$ column  
gives~$F\!$.

Those truth tables use \definend{Boolean variables}
such as $P$ and~$Q$, which can take on values of either \true{} or \false\!.
We call each of those symbolic statements a
propositional logic \definend{expression}\index{Propositional logic!expression}
and denote it with a capital Roman letter such as~$E$.

% Observe that $\wedge$ accumulates \false{} 
% in that if any of its inputs are 
% $\false$ then $P\wedge Q$ is~$\false$.
% Similarly, $\vee$ accumulates~$\true$\!.

We prefer symbols to expressing the same ideas in words because 
we can describe more things, and with complete precision.
For instance, 
$(P\vee Q)\wedge \neg (P\vee (R\wedge Q))$ is not complicated
as a Boolean expression,
but it
is too complex to comfortably communicate using a natural language.
% say, where $P$ stands for `$7$ is odd', 
% $Q$ for `$9$ is a perfect square', and 
% $R$ stands for `$11$ is prime'. 
As to precision, when using symbols we can easily see that, for instance, 
$P\wedge (Q\vee R)$ and $(P\wedge Q)\vee R$ have different values
for some sets of inputs, such as \false-\true-\true\!.
But the distinction is
hard to make in a natural language sentence that is both simple and clear.

Truth tables help in calculating the input/output behavior 
of complex expressions.
The key is to build the expressions up from their components, and enter
the values for these constituent expressions as intermediate columns.
Below we find the behavior of~$E$, the expression
$(P\vee Q)\wedge \neg (P\vee (R\wedge Q))$ from the prior paragraph.

There are other operators; here are some frequently-used ones.\index{implication}\index{Propositional logic!implication}\index{exclusive or@exclusive or \textsc{XOR}}\index{XOR@\textsc{XOR}, exclusive or}\index{Propositional logic!exclusive or@exclusive or \textsc{XOR}}

Two statements are 
\definend{equivalent}\index{equivalent propositional logic statements}
(or \definend{logically equivalent}) 
if they 
have equal output values whenever we assign the same values to the 
input variables. 
For instance, $P\rightarrow Q$ is equivalent to $\neg P\vee Q$, because
if we assign $P=F, Q=F$ then they both give the value~$T$, 
if we assign $P=F, Q=T$ then they also give the same value, etc. 
Restated, statements are equivalent when their truth tables have the
same final column. 
We denote equivalence using $\equiv$, as with 
$P\rightarrow Q\equiv\neg P\vee Q$.

High school algebra covers rules to manipulate number statements
while retaining equality, such as that $x\cdot(y+z)=x\cdot y+x\cdot z$. 
The rules for manipulating   
Boolean statements is 
\definend{Boolean algebra}.\index{Boolean algebra}\index{Propositional logic!Boolean algebra}
An example is that $\neg\neg P\equiv P$ 
and so if an expression contains $\neg\neg P$
then we can replace it with~$P$ to get an equivalent expression.
Likewise, the above truth table says that
we can replace $P\mathrel{\text{XOR}} Q$ with $\neg(P\leftrightarrow Q)$.
Often used are the
distributive laws\index{distributive laws!for logic expressions}\index{Propositional logic!distributive laws}
\begin{equation*}
  P\wedge(Q\vee R)\equiv(P\wedge Q)\vee (P\wedge R) 
  \qquad
  P\vee(Q\wedge R)\equiv(P\vee Q)\wedge (P\vee R)  
\end{equation*}
and
\definend{DeMorgan's laws}.\index{DeMorgan's laws}\index{Propositional logic!DeMorgan's laws}
\begin{equation*}
  \neg(P\wedge Q)\equiv \neg P\vee \neg Q 
  \qquad
  \neg(P\vee Q)\equiv \neg P\wedge \neg Q  
\end{equation*}
One way to establish the correctness of each of these equivalences 
is to make truth tables for the two sides and compare final columns.

We can reverse the above activity\Dash given a 
truth table we can produce an expression
whose input/output behavior is that table. 
We can do that using only the operators `$\neg$', `$\wedge$', and~`$\vee$'.

One way to produce expressions is to 
focus on those rows where the 
final column is~\true\!.
The table on the left has one such row, where $P=\false$ and $Q=\false$. 
Thus for $E_0$ we can use $\neg P\wedge \neg Q$. 

Similarly, for the table on the right, 
target the second row with the expression $\neg P\wedge \neg Q\wedge R$,
target the third row with $\neg P\wedge Q\wedge \neg R$,
and target the fifth with $P\wedge\neg Q\wedge\neg R$.
Then join these with $\vee$'s.
\begin{equation*}
  (\neg P\wedge \neg Q\wedge R)
  \vee(\neg P\wedge Q\wedge \neg R)
  \vee(P\wedge\neg Q\wedge\neg R)
\tag{$*$}
\end{equation*}

In the the syntax of Boolean expressions,
we refer to each variable as an \definend{atom}.
An atom or its negation, such as $P$ or $\neg P$, is a \definend{literal}.
A \definend{clause} is a number of literals joined by a common connective,
such as $\neg P\wedge\neg Q\wedge R$ 
(we will stick with either $\wedge$ or $\vee$).
Then a propositional logic expression is in 
\definend{disjunctive normal form}\index{disjunctive Normal form, DNF}\index{DNF}\index{Propositional logic!disjunctive normal form, DNF}
or \definend{DNF}
if it has the form of~($*$), 
a disjunction of clauses where each clause is a conjunction of literals.

Symmetry requires that there be a normal form based on $\false$ rows.
Consider~$E_0$'s table.
The second, third, and fourth rows are~$\false$\!.
Targeting those rows, forming the DNF, and taking the negation gives 
$\neg\big((\neg P\wedge Q)\vee(P\wedge\neg Q)\vee(P\wedge Q)\big)$.
Use DeMorgan's second law to distribute the outside negation,
$\neg(\neg P\wedge Q)\wedge\neg(P\wedge\neg Q)\wedge\neg(P\wedge Q)$.
Then use  DeMorgan's first law to distribute the three leading negations,
yielding
$(P\vee \neg Q)\wedge(\neg P\vee Q)\wedge(\neg P\vee \neg Q)$.
\definend{Conjunctive normal form}\index{conjunctive normal form, CNF}\index{Propositional logic!conjunctive normal form, CNF}
or \definend{CNF}
has a conjunction of clauses, where each clause is a disjunction of literals.

To get a shortcut, notice the pattern in the prior paragraph's result. 
We illustrate with $E_1$'s table.
There are five clauses, one for 
each of the five \false{} lines. 
Those clauses are joined with $\wedge$'s.
As to the makeup of the clauses:~there is a literal for each variable, 
joined with $\vee$'s.
If on the associated~\false{} line a variable $X$ is assigned \true{} 
then inside the clause write $\neg X$,
and if $X$ is assigned~\false{} then write~$X$.
\begin{equation*}
  (P\vee Q\vee R)
    \wedge(P\vee \neg Q\vee \neg R)
    \wedge(\neg P\vee Q\vee \neg R)       
    \wedge(\neg P\vee \neg Q\vee R)
    \wedge(\neg P\vee \neg Q\vee \neg R)
    \tag{$**$}
\end{equation*}
For example, 
% in $E_1$'s first \false{} line all three variables have been
% assigned~\false{} so we fill the clause with $P\vee Q\vee R$.
the second of $E_1$'s \false{} lines is its fourth row.
There $P$ is assigned~\false{} while $Q$ and~$R$
are assigned~\true\!, and so the second clause is 
$P\vee \neg Q\vee \neg R$. 
(Thus ($*$) and ($**$), while unequal expressions, both have the input/output
behavior of the right-hand table.)

We use CNF more than DNF.
It has the advantage that 
an expression gives~\true{} if and only if 
all of its clauses are~\true{}\!.
And, a clause is \true{}  
if and only if at least one of its literals is~$\true\!$.

A \definend{Boolean function}\index{Boolean function}\index{function!Boolean}\index{Propositional logic!Boolean function}
has inputs that are Boolean, either $T$ or~$F$, 
and outputs that are also Boolean.
By the prior paragraphs, any desired single-output Boolean function is
determined by some Boolean expression.
If needed, we can give such an expression either in
DNF or~CNF.
(And, a two-output Boolean function is determined by two Boolean
expressions, etc.)

\begin{exercise}
Express
$(P\vee Q)\wedge \neg (P\vee (R\wedge Q))$ as clearly as possible
in a couple of sentences,
taking $P$ to stand for `$7$ is odd', 
$Q$ for `$9$ is a perfect square', and 
$R$ for `$11$ is prime'.
\begin{answer}
Obviously `clearly' is open to interpretation
but here is a try:
\textit{Two things must both be true.
The first is that either $7$ is odd or $9$ is a perfect square.
The second is that it must not be either the case that $7$ is odd 
or the case that both $11$ is prime and $9$ is a perfect square.}
In any event, the idea is much harder to understand in words than in symbols.
\end{answer}
\end{exercise}

    $\true$  &$\false$  &$\false$  &$\false$    \\
    $\true$  &$\false$  &$\true$  &$\false$    \\
    $\true$  &$\true$  &$\false$  &$\true$    \\
    $\true$  &$\true$  &$\true$  &$\true$    
  \end{tabular}  
\end{center}
\begin{answer}\verified
In Disjunctive Normal form the clauses are separated by disjuncts.
\begin{exparts}
\item
The second, third and sixth lines show \true.
The associated clauses are $\neg P\wedge\neg Q\wedge R$, 
$\neg P\wedge Q\wedge \neg R$,
and
$P\wedge\neg Q\wedge R$.
The resulting CNF expression is this.
\begin{equation*}
  (\neg P\wedge\neg Q\wedge R)
  \vee
  (\neg P\wedge Q\wedge \neg R)
  \vee
  (P\wedge\neg Q\wedge R)
\end{equation*}
\item
The \true{} lines give four clauses.
\begin{equation*}
  (\neg P\wedge \neg Q\wedge \neg R)
  \vee (\neg P\wedge Q\wedge \neg R)
  \vee (P\wedge Q\wedge \neg R)
  \vee (P\wedge Q\wedge R)
\end{equation*}
\end{exparts}
\end{answer}
\end{exercise}
