\section{串}\label{sec:Strings}\index{string|(}\thispagestyle{empty}

%<*def:Alphabet>
一个 \definend{字母表}\index{alphabet}
是一个非空、有限的\definend{符号}\index{symbol}
或\definend{记号}\index{token}的集合。
我们使用打字机字体来书写符号，例如 \str{1} 或 \str{a}，
因为用引号括起来的方式显得太笨拙。\footnote{%
  使用打字机字体还能区分符号"\protect\str{a}"和变量"$a$"，
  这样我们就能分清"令 $x=\str{a}$"和"令 $x=a$"。
  符号不是变量\Dash 它们不持有值，它们本身就是值。}
%</def:Alphabet>
%<*def:String>
字母表上的一个 \definend{串}\index{string}
或\definend{字}\index{word over an alphabet|see {string}}
是该字母表元素的一个有限序列。
没有元素的串是
\citetext{\definend{空串（empty string）}，记为~$\emptystring$}{或许
  $\emptystring$ 是"empty"的缩写。
  有些作者用 $\lambda$，可能源自德语中表示"空"的词 \textit{leer}。
  也可能只是因为需要这么一个符号而有人用了它；传闻当被问及为何在他的 $\lambda$ 演算中使用 $\lambda$ 符号时，
  Church 回答："eenie, meenie, meinie, mo"\autocite{csse:Siren}；亦可参见
  \url{https://www.youtube.com/watch?v=juXwu0Nqc3I}}。\index{string!empty}\index{empty string@empty string, $\emptystring$}
%</def:String>

%<*discussion:SymbolsMayContainMoreThanOneChar>
符号有一个可能令人惊讶的特点：
它可以包含不止一个字符。
例如，一门编程语言
可能将 \str{if} 作为一个符号，它不可分解为单独的字母。
%</discussion:SymbolsMayContainMoreThanOneChar>
另一个例子是，Racket 语言的字母表
包含符号 \str{or} 和 \str{car}，同时也允许
诸如 \str{lastname} 这样的符号作为变量名。
Racket 中一个串的例子是 $\str{(or a ready)}$，它是
五个字母表元素的序列，
$\sequence{\str{(}, \str{or}, \str{a}, \str{ready},\str{)}}$。

%<*discussion:AlphSymbol>
传统上用大写希腊字母~$\Sigma$ 表示字母表。\footnote{%
  封底内页列出了希腊字母及其读音。}
我们使用小写希腊字母来命名串
（但我们保留~$\TMfcn$ 另作他用），
并使用对应的小写罗马字母来表示串中的符号，如
$\sigma=\sequence{s_0,\ldots\, s_{n-1}}$
和 $\tau=\sequence{t_0,\ldots\, t_{m-1}}$。
%</discussion:AlphSymbol>
\label{def:StringLength}
%<*def:StringLength>
串 $\sigma$ 的\definend{长度}，
\definend{$\lh{\sigma}$},\index{string!length}\index{length!of a string}，
是它包含的符号个数，即~$n$。
特别地，
空串的长度是 $\lh{\emptystring}=0$。
%</def:StringLength>

有时我们使用方括号 $\sigma[i]$ 来代替下标记号 $s_i$。
好处之一是我们可以用 $\sigma[-1]$ 表示最后一个符号，
用 $\sigma[-2]$ 表示倒数第二个，等等。
我们还用 $\sigma[i\mathord{:} j]$ 表示
从~$s_i$ 到~$s_j$ 的符号子序列（包括 $s_i$ 但不包括~$s_j$），
用 $\sigma[i\mathord{:}]$ 表示从~$s_i$ 开始的尾部，
以及用 $\sigma[\mathord{:} j]$ 表示 $\sigma[0\mathord{:} j]$。

%<*dis:OmitCommas>
为了方便起见，我们通常处理
符号为单字符的字母表，
这样就可以省略括号和逗号来书写串。
也就是说，我们更喜欢写 $\sigma=\str{abc}$，
而不是 $\sequence{\str{a},\str{b},\str{c}}$。\footnote{%
  要理解为何省略逗号时希望字母表由单字符符号组成，考虑
  $\Sigma=\set{\str{a}, \str{aa}}$
  和串 $\str{aaa}$。
  没有逗号时，这个串是歧义的，因为它可能
  表示~$\sequence{\str{a},\str{a}, \str{a}}$、$\sequence{\str{a},\str{aa}}$、
  $\sequence{\str{aa},\str{a}}$、
  或~$\sequence{\str{aaa}}$。}
%</dis:OmitCommas>
这种做法也
带来一个缺点：没有尖括号时，
空串就什么也不是，这就是为什么
我们保留了一个单独的符号~$\emptystring$。\footnote{%
  省略括号和逗号也模糊了符号与单符号串之间的区别，即模糊了 \str{a} 和 $\sequence{\str{a}}$ 之间的区别。
  但这种写法非常方便，我们接受了这个缺点。}

%<*def:Bitstrings>
由比特字符组成的字母表是
\definend{$\B=\set{\str{0},\str{1}}$}
（我们有时也用 $\B$ 表示比特自身的集合 $\set{0,1}$）。
$\B$ 上的串称为\definend{比特串（bitstrings）},\index{bitstring}\index{bitstring!set of@set of, $\B$}
或\definend{比特串（bit strings）}。\index{bit string|see{bitstring}}
%</def:Bitstrings>

%<*def:KleeneStar>
设~$\Sigma$ 是一个字母表，
对于 $k\in\N$，
该字母表上长度为~$k$ 的串的集合是
\definend{$\Sigma^k\!$}。
$\Sigma$ 上所有有限长度的串的集合是
\definend{$\kleenestar{\Sigma}=\cup_{k\in\N}\Sigma^k\!$}。
星号符号称为\definend{Kleene 星（Kleene star）},\index{Kleene star}
读作"星"。
%</def:KleeneStar>

%<*def:StringOps>
串的操作只有寥寥几种。
令 $\sigma=\sequence{s_0,\ldots\, s_{n-1}}$ 和
$\tau=\sequence{t_0,\ldots\, t_{m-1}}$ 是同一字母表上的串。
\definend{拼接 $\sigma\concat\tau$（concatenation）} 或 \definend{$\sigma\tau$}\index{concatenation!of strings}\index{string!concatenation}
将第二个串附加到第一个串之后，$\sigma\concat\tau=\sequence{s_0,\ldots\, s_{n-1},t_0,\ldots\, t_{m-1}}$。
\label{def:substring}
当
$\sigma=\tau_0\concat \cdots \concat\tau_{k-1}$ 时，我们说
$\sigma$ \definend{分解（decomposes）}\index{string!decomposition}
为这些 $\tau$，并且每个 $\tau_i$ 是 $\sigma$ 的一个
\definend{子串（substring）}\index{substring}\index{string!substring}。
第一个子串，$\tau_0$，是 $\sigma$ 的一个
\definend{前缀（prefix）}\index{prefix of a string}\index{string!prefix}。
最后一个，$\tau_{k-1}$，是
\definend{后缀（suffix）}。\index{suffix of a string}\index{string!suffix}

串的
\definend{幂（power）}\index{power of a string}\index{string!power}
或称
\definend{重复（replication）}\index{replication of a string}\index{string!replication}
就是与自身迭代拼接，因此 $\sigma^2=\sigma\concat\sigma$
和 $\sigma^3=\sigma\concat\sigma\concat\sigma$，等等。
我们记 $\sigma^1=\sigma$ 且 $\sigma^0=\emptystring$。
\citetext{\definend{串的反转（reversal $\reversal{\sigma}$）}{}}{%
  当前最实用的串的概念——Unicode 标准——并没有定义串的反转操作。
  所有朴素的反转串的方法在处理任意 Unicode 串时都会遇到问题，因为这些串可能包含非 ASCII 字符、组合字符、连字、多种语言的双向文本等等。
  例如，仅仅反转串中的字符（Unicode 标量值）会导致组合标记附着到错误的字符上。
  另一个例子是：如何反转 \str{ab<backspace>ab}？
  Unicode 联盟并未花费精力去定义串的反转，因为现实世界中并没有这个需求。
  （摘自 \url{https://qntm.org/trick}。）}\index{reversal!of a string}\index{string!reversal}
是指按相反顺序取出符号：~$\reversal{\sigma}=\sequence{s_{n-1}, \ldots\, s_0}$。
空串的反转是
$\reversal{\emptystring}=\emptystring$。
%</def:StringOps>

例如，
令 $\Sigma=\set{\str{a},\str{b},\str{c}}$，并设
$\sigma=\str{abc}$ 和 $\tau=\str{bbaac}$。
那么，拼接 $\sigma\tau$ 的结果是 \str{abcbbaac}。
三次幂 $\sigma^3$ 是 \str{abcabcabc}，
而反转 $\reversal{\tau}$ 是 \str{caabb}。
%<*def:Palindrome>
\definend{回文（palindrome）}\index{palindrome}
是等于其自身反转的串。
例如：
$\alpha=\str{abba}$、$\beta=\str{cdc}$ 以及 $\emptystring$。
%</def:Palindrome>

\begin{exercises}


\begin{exercise}
设 $\sigma=\str{10110}$ 和 $\tau=\str{110111}$ 为比特串。
求以下各式。
\begin{exparts*}
\item $\sigma\concat \tau$
\item $\sigma\concat\tau\concat\sigma$
\item $\reversal{\sigma}$
\item $\sigma^3$
\item $\str{0}^3\concat\sigma$
\end{exparts*}
\begin{answer}
\begin{exparts}
\item $\sigma\concat \tau=\str{10110}\concat\str{110111}=\str{10110110111}$。
\item $\sigma\concat\tau\concat\sigma=
   \str{10110}\concat\str{110111}\concat\str{10110}=\str{1011011011110110}$
\item $\reversal{\sigma}=\reversal{\str{10110}}=\str{01101}$
\item $\sigma^3=\str{10110}\concat\str{10110}\concat\str{10110}
               =\str{101101011010110}$
\item $\str{0}^3\concat\sigma=\str{000}\concat\str{10110}=\str{00010110}$
\end{exparts}
\end{answer}
\end{exercise}

\begin{exercise}
设字母表为 $\Sigma=\set{\str{a},\,\str{b},\,\str{c}}$。
假设 $\sigma=\str{ab}$，$\tau=\str{bca}$。
计算下列各式。
\begin{exparts*}
\item $\sigma\concat\tau$
\item $\sigma^2\concat\tau^2$
\item $\reversal{\sigma}\concat\reversal{\tau}$
\item $\sigma^3$
\end{exparts*}
\begin{answer}
\begin{exparts}
\item \str{abbca}
\item \str{ababbcabca}
\item \str{baacb}
\item \str{ababab}
\end{exparts}
\end{answer}
\end{exercise}

\begin{exercise}
设$\lang=\set{\sigma\in\kleenestar{\B}\suchthat 
   \text{$\lh{\sigma}=4$ 且 $\sigma$ 以 \str{0} 开头}}$。
这个语言中有多少个元素？
\begin{answer}
长度为~$4$ 的比特串有 $2^4=16$ 个，其中一半以 \str{0} 开头，因此该语言中有 $8$ 个串。
\end{answer}
\end{exercise}

\begin{exercise}
假设 $\Sigma=\set{\str{a},\,\str{b},\str{c}}$ 且 $\sigma=\str{abcbccbba}$。
\begin{exparts*}
\item \str{abcb} 是 $\sigma$ 的前缀吗？
\item \str{ba} 是 $\sigma$ 的后缀吗？
\item \str{bab} 是 $\sigma$ 的子串吗？
\item \emptystring{} 是（$\sigma$ 的）后缀吗？
\end{exparts*}
\begin{answer}
\begin{exparts}
\item 是。
\item 是。
\item 否。
\item 是。
\end{exparts}
\end{answer}
\end{exercise}

\begin{exercise}
$\lh{\sigma}$、$\lh{\tau}$ 与 $\lh{\sigma\concat\tau}$ 之间的关系是什么？
你必须论证你的答案。
\begin{answer}
拼接串的长度等于两串长度之和：$\lh{\sigma\concat\tau}=
\lh{\sequence{s_0,\ldots\, s_{i-1},t_0,\ldots\, t_{j-1}}}=i+j=\lh{\sigma}+\lh{\tau}$。
\end{answer}
\end{exercise}

\begin{exercise}
串的拼接操作遵循简单的代数规律。
对于下列每一条，判断其真假。
若为真，则予以证明；若为假，则举出反例。
\begin{exparts*}
  \item $\alpha\concat\emptystring=\alpha$
    且 $\emptystring\concat\alpha=\alpha$
  \item $\alpha\concat\beta=\beta\concat\alpha$
  \item $\reversal{\alpha\concat\beta}=\reversal{\beta}\concat\reversal{\alpha}$
  \item $\reversal{\reversal{\alpha}}=\alpha$
  \item $\reversal{\alpha^i}=\alpha^i$
\end{exparts*}
\begin{answer}
\begin{exparts}
\item 真。
  第一式 $\alpha\concat\emptystring$ 的拼接结果就是
  $\alpha\concat\emptystring=\sequence{a_0,\ldots\, a_{i-1}}\concat\sequence{}=\sequence{a_0,\ldots\, a_{i-1}}=\alpha$。
  第二式的证明方法类似。
\item 假。
  反例为两个比特串 $\alpha=\str{0}$ 和 $\beta=\str{1}$。
\item 假。
  与前一项情况类似，
  反例仍为两个比特串 $\alpha=\str{0}$ 和 $\beta=\str{1}$。
\item 真。
  当 $\alpha=\sequence{a_0,\ldots\, a_{i-1}}$
  时，我们有 $\reversal{\alpha}=\sequence{a_{i-1},\ldots\, a_{0}}$，
  因此 $\reversal{\reversal{\alpha}}=\sequence{a_{0},\ldots\, a_{i-1}}$。
\item 假。
  反例为比特串 $\alpha=\str{01}$，取幂次 $i=1$。
\end{exparts}
\end{answer}
\end{exercise}
