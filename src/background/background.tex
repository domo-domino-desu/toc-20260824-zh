Here we will develop the ideas surrounding the definition of 
mechanical computation.
We will see several results that are a theme throughout the subject.

One point made in the prior chapter is that we prefer an extensional
approach:~we are interested in the 
things that are computed more than in the low-level details
of exactly how they are computed.
In particular, we are interested in the functions $\map{f}{\N}{\N}$
that are effective, 
that are computed by Turing machines.
The major result of the chapter, the single most important result in the 
book, is that there are functions that are uncomputable\Dash 
there is no Turing machine to compute them.
There are jobs no machine can do.





\section{Infinity}

We will show that there are more functions than 
Turing machines, and that therefore some functions have no 
associated machine.

The set of functions and the set of Turing machines are both
infinite so 
we must
understand how to compare the sizes of infinite sets. 
We will begin with two paradoxes, two examples that
dramatize the challenge to our intuition posed by 
comparing the sizes of infinite sets.

The first is 
\definend{Galileo's Paradox},\footnote{He did not invent this paradox but
he gave it prominence in his celebrated
\protect\textit{Discourses and Mathematical Demonstrations Relating to Two New Sciences}.}
comparing the size of the set of perfect squares with the size of the set of 
all natural numbers.
There are fewer perfect squares than natural numbers in the sense that
the first set is a proper subset of the second, so
there are some natural numbers that are not squares.
However, there are exactly as many squares as natural numbers in the sense that
the two sets can be made to correspond, 
to match element-to-element, as illustrated in the figure below.   
\begin{animatedfigure}{Correspondence $n\leftrightarrow n^2$ between the 
  natural numbers and the squares.} 
\animategraphics{3}{background/asy/galileo/galileo}{000}{012}
\end{animatedfigure}
\noindent In the children's game Musical Chairs, 
there are more people than there are chairs. 
The music plays and the children walk around but when the music
stops, and each tries to sit,
someone is left without a chair.
That is, between the set
of available chairs and the set of people sitting is a correspondence. 
This correspondence demonstrates,
without counting, that the two sets have the same number of elements.

Our second paradox of the infinite is is \definend{Aristotle's Paradox}.
Everyone knows that a smaller circle has a smaller circumference.

Those two paradoxes point out that there is more than one way
to make precise the idea that one set is `bigger' than another
and these ways may not give the same answer.
The idea we will adopt is that
to compare two sets with respect to the the number of elements they contain,
we should see whether they correspond.

Recall that a correspondence is a function that is both onto and 
one-to-one.

\begin{lemma} \label{lem:OneToOneOntoFiniteSets}
Suppose that finite sets have a map between them $\map{f}{D}{C}$.
If $f$ is onto then $D$ has at least as many elements as $C$.
If $f$ is one-to-one then $D$ has at most as many elements as $C$.
% Therefore, between two finite sets there is a correspondence 
% if and only if they have the same number of elements.
\end{lemma}

\begin{proof}
See \cref{exer:FiniteSetsSamSizeIffCorres}.

% the statements about one-to-one and onto. 
% From those two, the final sentence is clear.
\end{proof}

\begin{definition} \label{def:Cardinality}
Two sets have the \citetext{same \definend{cardinality}}{Numbers 
have two natures.
First, in referring to the Pleiades as
the ``Seven Sisters'' we mean to take them as a set, not 
ordered in any way.
In contrast, second, in referring to the ``Seven Deadly Sins,'' well,
clearly some of them rate higher than others.
The first reference speaks to the cardinal nature of numbers 
and the second is their ordinal nature.
For finite numbers the two are bound together,
as \protect\cref{ex:SizeThreeSets} suggests,
but for infinite numbers they differ.} 
(or are \definend{equinumerous})
if there is a correspondence between them.  
That is, sets $S_0$ and $S_1$ have the same cardinality
if there is a 
one-to-one and onto function $\map{f}{S_0}{S_1}$.
If so, we write $\sizeof{S_0}=\sizeof{S_1}$.
\end{definition}

By the lemma, finite sets have the same cardinality just if they have
the same size, the same number of elements.
The definition's main interest is that it extends
this same-size relation to infinite sets.
The vertical bar notation extends the notation for 
finite sets, when we just state the set's size as in $\sizeof{\set{0,1,2}}=3$.

\begin{example}  \label{ex:SizeThreeSets}
The set of numbers $S_0=\set{0,1,2}$ and set of
letters $S_1=\set{\alpha,\beta,\gamma}$ have the same cardinality,
$\sizeof{S_0}=\sizeof{S_1}$, as
witnessed by
the correspondence $0\mapsto\alpha$, $1\mapsto\beta$, $2\mapsto\gamma$.
This function is one-to-one because just checking the three cases shows that
for each member of the codomain~$S_1$ there is at most one associated member
of the domain~$S_0$.
This function is onto because checking also shows that for each member
of~$S_1$ there is at least one member of~$S_0$ that maps to it.

That function is natural but is not unique.
Another is $0\mapsto\beta$, $1\mapsto\alpha$, $2\mapsto\gamma$.
As with the prior paragraph, we can see that this is a correspondence 
by inspection.
\end{example}

\begin{example} \label{ex:PerfectSquaresCountable}
Galelio's Paradox is that the set of perfect squares 
$S=\set{n^2\suchthat n\in\N}$
has the same cardinality as the set $\N$, 
under the correspondence $\map{f}{\N}{S}$ given by $f(n)=n^2$.
This map is one-to-one because if 
$f(n_0)=f(n_1)$ so that $n_0^2=n_1^2$, then because these are natural 
numbers $n_0=n_1$.
It is onto because any element of the codomain $s\in S$
is the square $s=n^2=f(n)$ of some~$n\in\N$, by definition of~$S$.  
\end{example}

\begin{example} \label{ex:RealIntervalsCorrespond}
As Aristotle observed, with nonzero $r_0, r_1\in\R$,
the interval $I_0=\leftclosed{0}{2\pi r_0}$ has the 
same cardinality as the interval $I_1=\leftclosed{0}{2\pi r_1}$, 
because the map
$\map{g}{I_0}{I_1}$ given by $g(x)=x\cdot(2\pi r_1/2\pi r_0)$
is a correspondence. 
The verification is \cref{exer:VerifyAsParadox}. 
\end{example}

\begin{definition}
A set $S$ is \definend{finite} if $\sizeof{S}=n$ 
for some $n\in\N$. 
Otherwise, it is \definend{infinite}.
\end{definition}

\margingraphic[l]{.25\textwidth}{background/GeorgCantor.png}{\label{fig:cantor}\href{http://en.wikipedia.org/wiki/Georg_Cantor}{Georg Cantor 1845--\-1918, discoverer of the transfinite numbers}} % https://upload.wikimedia.org/wikipedia/commons/6/67/Georg_Cantor3.jpg
Using correspondences to compare the sizes of sets, even infinite sets, 
\citetext{was proposed by Cantor in the 1870's}{For spreading the word about his discoveries, Cantor was reviled by a very prominent mathematician and former professor, Leopold Kronecker, as a ``corrupter of youth.''  Of course, that was pre-Elvis.}. 
\Cref{lem:OneToOneOntoFiniteSets} shows that it takes an idea that is 
natural in the finite case and extends it to apply to all sets.
However, as the paradoxes above show, \cref{def:Cardinality} introduces 
a deep idea.
Besides observing that it
generalizes the finite case, we should convince ourselves that
it captures what we mean by two sets 
having the `same number' of elements.

As with Turing's definition of his machine, 
the strength of this definition
is that it is clear\Dash it is persuasive in itself.
G\"odel noted this, writing,
``Whatever `number' as applied to infinite sets may mean, we certainly want it
to have the property that the number of objects belonging to some class does not change if,
leaving the objects the same, one changes in any way \ldots{}
e.g., their colors or their distribution in space \ldots{}\,.
From this, however, it follows at once that two sets will have the same
[cardinality] if their elements can be brought into one-to-one
correspondence, \citetext{which is Cantor's definition}{\autocite{Godel64}}.''

to mention here,

For the study of computation, 
\citetext{the key example of an infinite set is $\N$}{Its existence is 
guaranteed by the Axiom of Infinity, one of the standard axioms of Mathematics,
the Zermelo-Frankel axioms.}.

\begin{definition}
A set with the same cardinality as $\N$ is \definend{countable}
or \definend{countably infinite}.
We shall call exhibiting a correspondence $\map{f}{\N}{S}$ 
\definend{counting} or \definend{enumerating} that set.
\end{definition}

\begin{example} \label{ex:MultiplesOfThreeCountable}
The set of multiples of three $\set{3k\suchthat k\in\N}$ is countable. 
The natural correspondence is $g(n)=3n$. 
\end{example}

\begin{example} \label{ex:NWithGapsCountable}
The set $\N-\set{2,5}=\set{0,1,3,4,6,7,\ldots}$ is countable.
This tabular display of a suitable function $\map{f}{\N}{\N-\set{2,5}}$
\begin{equation*}
  \begin{array}{r|ccccccc}
    n\in\N
      &0 &1 &2 &3 &4 &5 &\ldots \\ \cline{2-8}
    f(n)\in\N-\set{2,5}
      &0
      &1
      &3
      &4
      &6
      &7
      &\ldots
  \end{array}
\end{equation*}
gives the intuition that we just close up to fill the gaps.
The definition
\begin{equation*}
  f(n)=\begin{cases}
         n    &\case{if $n<2$}  \\
         n+1  &\case{if $n\in\set{2,3}$} \\
         n+2  &\case{if $n\geq 4$}
       \end{cases}
\end{equation*}
leads to an easy verification that $f$ both one-to-one and onto.
\end{example}

\begin{example} \label{ex:PrimesCountable}
The set~$\mathcal{P}$ of prime numbers is countable.
For the correspondence $\map{f}{\N}{\mathcal{P}}$ we won't give a 
formula.
Instead we can define the function as the input-output behavior of a 
program; just write one that reads in a natural number~$n$ and prints out 
the $n$-th prime
(taking the $0$-th prime to be~$2$, the $1$-th to be~$3$, etc.).
Showing that the function is a correspondence is straightforward.
\end{example}

\begin{example}  \label{ex:StringsCountable}
Consider the alphabet, the set of characters, 
$\Sigma=\set{\str{a},\ldots,\str{z}}$.
Also consider the set of finite-length strings made of 
those characters, denoted $\kleenestar{\Sigma}$.
For instance, three members of $\kleenestar{\Sigma}$ are 
\str{abc}, \str{xyz}, and~\str{abba}.
The set $\kleenestar{\Sigma}$ is countable.
As in the prior example we won't give a formula but this tabular presentation
of the function makes clear that we get a correspondence by 
taking the strings in the 
ascending dictionary order.
(The first one is the empty string, 
$\emptystring=\text{`\,'}$.)
\begin{center}
  \begin{tabular}{r|cccccccc}
    $n\in\N$  &$0$    &$1$   &$2$ &$\ldots$  &$26$  &$27$ &$28$ &$\ldots$   
   \\ \cline{2-9}
    $f(n)\in\kleenestar{\Sigma}$  &$\emptystring$  &\str{a} &\str{b} &$\ldots$ 
    &\str{z} &\str{aa} &\str{ab}  &$\ldots$
  \end{tabular}
\end{center}
Inverting the correspondence,
going from table's bottom row to its top, 
shows that we can use the alphabet to make enough words to 
name each element of a countably infinite set, 
even though the alphabet is finite.

\end{example}

The obvious next set to tackle is $\N\times\N$.

\subsection{Cantor in code}
The definitions of cardinality and countability
do not require that the functions are
effective.
In this section we effectivize, 
showing how to count such sets as 
$\set{0,1}\times\N$ and $\N\times\N$ 
using functions that are mechanically computable.
The most straightforward way to show that these functions can be computed is to 
exhibit code, so that is what we do.

\Cref{af:EnumerateNxN} does a breadth-first coverage
of the array by
\citetext{counting diagonally}{Some authors call this an anti-diagonal, 
taking the diagonal to be composed of the pairs $\sequence{n,n}$.}.
\begin{center}
  \includegraphics{background/asy/correspondences/correspondences3000.pdf}
\end{center}
For the idea behind the formula, consider the pair~$\sequence{1,2}$ in
the above figure.
The number of its diagonal, $3$, is the sum of its entries.
Also, before diagonal~$3$ are six pairs, 
so that on diagonal~$3$ the initial pair~$\sequence{0,3}$ 
gets counted as pair~$6$, and then
$\sequence{1,2}$ corresponds to~$7$.

Following that pattern, to get the number corresponding to~$\sequence{x,y}$
first observe that it lies on diagonal $d=x+y$.
Diagonal~$0$ has one entry, diagonal~$1$ has
two entries, diagonal~$2$ has three entries, etc.,
so the number of entries prior to diagonal~$x+y$ is $1+2+\cdots+d$.
This is an arithmetic series with total $d(d+1)/2$, 
called the $d$-th \definend{triangle number}.
Then, inside diagonal~$d$, the pair at the start is $\sequence{0,x+y}$,
next is~$\sequence{1,x+y-1}$, etc., and so
$\sequence{x,y}$ is the~$x$-th pair from $d$'s start.

\begin{definition}
\definend{Cantor's correspondence} $\map{\cantor}{\N^2}{\N}$
(or \definend{Cantor's unpairing function}, or
the \definend{diagonal} enumeration) is
\citetext{$\cantor(x,y)=(1/2)(x+y)(x+y+1)+x$}{The 
Fueter-P\'olya Theorem says that this is essentially the only 
quadratic function that serves as a pairing; see \autocite{Smorynski}.
No one knows whether there are pairing functions 
that are any other kind of polynomial.}.
\end{definition}

\begin{equation*}

\end{equation*}

\citetext{take the floor}{Let the $n$-th triangle number be
$t(n)=0+1+\cdots+n=n(n+1)/2$.

that is maximal so that $c=t(n)+k$ for some~$k\in\N$.

\Cref{ex:PrimesCountable} and \cref{ex:StringsCountable} argued
that the set of prime numbers and the set of strings over a finite
alphabet are countable.
But they used constructions that were hand-wavy.
We can now make such arguments more precisely.

\begin{example}  \label{ex:RationalsAreCountable}
We will show that the set of rational numbers $\Q$ is countable.
We already know how to alternate between positives and negatives, 
so that reduces the problem of finding a correspondence 
to that of just doing the nonnegatives $\map{f}{\N}{\Q^+\cup\set{0}}$.
A nonnegative rational is a pair 
$\sequence{\text{numerator},\text{denominator}}$,
with the numerator a member of $\N$ and the denominator a member
of $\N+$, except
that some pairs collapse; for instance, $4/2$ equals~$2/1$.

As we did when counting the prime numbers, we will count the nonnegative 
rationals not with a formula but instead with a program, with a 
function that is computable.
To avoid counting both~$4/2$ and~$2/1$, we 
\citetext{memoize}{A memoized routine for computing a function
saves the results of computing 
that function on previously-seen inputs, and then can reuse those results. 
For instance, if a memoized factorial function has been used to compute
$5!=120$ and later is asked to compute $6!$, it can simply
do $6\cdot 120$ instead of having to compute the $120$ all over again.
(The term was invented by Donald Michie~\autocite{wiki:Michie}, 
a coworker of Turing's in the World War~II effort to break the 
German secret codes.)}. 
That is, to list the rational numbers
we generate the pairs $\sequence{a,b}$ in ascending order, 
\codeinline{(xy 0)}, \codeinline{(xy 1)}, etc.
For such a pair $\sequence{a,b}$, we reject it as the next rational
number to be listed if $b=0$.
We also reject it if the fraction $a/b$ is equivalent to a previously listed
fraction.
Otherwise, we enumerate it as the next nonnegative rational.
\Cref{exer:CodeForRationalsCountable} asks for the Scheme code to compute
this function.
\end{example}

\begin{exercise}
Verify \cref{ex:MultiplesOfThreeCountable}, that the function 
$\map{g}{\N}{\set{3k\suchthat k\in\N}}$ given by $n\mapsto 3n$ is
both one-to-one and onto.
\begin{answer}
To show that the map is one-to-one we will show that $g(n)=g(\hat{n})$ can only
happen if $n=\hat{n}$.
So let $g(n)=g(\hat{n})$, giving $3n=3\hat{n}$, and dividing by three 
yields $n=\hat{n}$, as required.

To show the map is onto we will show that every member of the codomain
$y\in\set{3k\suchthat k\in\N}$ is mapped-to by some member of the domain.
Because $y$ is a multiple of three, $y/3$ is a natural number.
Of course, $y=g(y/3)$, so $y$ is indeed the image of some member of the
domain.   
\end{answer}
\end{exercise}


\begin{exercise}
Show that each pair of sets has the same cardinality by 
producing a one-to-one and onto function.
\begin{exparts}
\item $\set{0,1,2}$, $\set{3,4,5}$
\item the set~$\Z$ of integers and the set $\set{i^3\suchthat i\in\Z}$ of cubes
\end{exparts}
\begin{answer}
\begin{exparts}
\item The map $f$ given by $f(0)=3$, $f(1)=4$, and $f(2)=5$, 
  that is, $f(x)=x+3$, is onto and one-to-one because by inspection
  we see that every element of the codomain has one and only one
  associated element of the domain.
\item The function $f(x)=x^3$ is a correspondence between these sets.
  It is one-to-one because for each cube there is only one associated
  cube root.
  It is onto because each perfect cube has an integer cube root.
\end{exparts}
\end{answer}
\end{exercise}


\begin{exercise}
Show that the set of powers of two $\set{2^k\suchthat k\in\N}$ 
and the set of powers of three  $\set{3^k\suchthat k\in\N}$ 
have the same cardinality.  
Generalize.
\begin{answer}
Let $P_2=\set{2^k\suchthat k\in\N}$ and $P_3=\set{3^k\suchthat k\in\N}$. 
The natural correspondence $\map{g}{P_2}{P_3}$ associates elements with
the same exponent $g(2^k)=3^k$.
This function is one-to-one because if the function yields two equal 
outputs~$g(2^{k_0})=g(2^{k_1})$ then
$3^{k_0}=3^{k_1}$ and taking the logarithm base~$3$ of both sides shows
that the inputs were the same~$k_0=k_1$.
The function is onto because if $y\in P_3$ then it has the form $y=3^k$,
and is the image of~$2^k\in P_2$.

The natural generalization is that for any two natural numbers 
$a,b>1$, the sets $P_a=\set{a^k\suchthat k\in\N}$ and 
$P_b=\set{b^k\suchthat k\in\N}$ have the same cardinality.
The argument is just as in the prior paragraph.
\end{answer}
\end{exercise}


\begin{exercise}
For each pair, show that the two sets have the same cardinality.
In addition to giving a suitable function, you must verify
that it is one-to-one and onto.   
\begin{exparts}
\item $\N$ and the even numbers $\set{2n\suchthat n\in\N}$
\item $\N$ and the odd numbers
\item the even numbers and the odd numbers
\end{exparts}
\begin{answer}
\begin{exparts}
\item Consider the function $\map{f}{\N}{\set{2n\suchthat n\in\N}}$
defined by $f(n)=2n$.
To verify that $f$ is one-to-one, assume that two inputs yield the same
output $f(n)=f(\hat{n})$, giving $2n=2\hat{n}$, and divide by~$2$ to
get that the two inputs are the same $n=\hat{n}$.

To verify that $f$ is onto, consider a member of the codomain $y$,
use the definition of the codomain to rewrite it as $y=2n$,
and solve for $n$ to get that there is an input associated with
this output, namely $n=y/2$ (dividing the output by two will yield a
natural number because $y$ is an even natural number).
\item We use the map $\map{g}{\N}{\set{2n+1\suchthat n\in\N}}$ 
given by $n\mapsto 2n+1$.
To verify that $g$ is one-to-one, assume that $g(n_0)=g(n_1)$, 
so that $2n_0+1=2n_1+1$.  
Subtract~$1$ and divide by~$2$ to conclude that  
$n_0=n_1$.

To verify that $g$ is onto we start with an element of the codomain
$y\in\set{2n+1\suchthat n\in\N}$.
Observe that because $y$ is odd, it has the form $y=2n+1$ for some
natural number~$n$.
Thus there is a natural number that maps under~$g$ to~$y$, 
namely~$n=(y-1)/2$, and thus~$g$ is onto.  
\item ONe answer involves using the two prior exercise parts, 
and knowing that the inverse of a correspondence is also a correspondence,
to get that the composition $\composed{f}{g^{-1}}$ is a correspondence from
the even numbers to the odds.

But a simpler answer is to consider the map $p$ from the evens to the odds 
given by $p(n)=n+1$.
Verification that $p$ is one-to-one and onto is easy.
\end{exparts}
\end{answer}
\end{exercise}

\begin{exercise}
Prove that 
the set $\N-\set{0}=\set{1,2,\ldots}$ is countable, using as a correspondence
the function $\map{f}{\N}{\N-\set{0}}$ given by
$f(n)=n+1$.
\begin{answer}
The function $f$ is one-to-one because if $f(n_0)=f(n_1)$ then
$n_0+1=n_1+1$ and so~$n_0=n_1$.
It is onto because if $y$ is an element of the 
codomain~$\N-\set{0}=\set{1,2,\ldots}$ then $y$ is the image of $y-1$, 
that is, $y=f(y-1)$,
and clearly $y-1$ is an element of the domain~$\N$.
\end{answer}
\end{exercise}


\begin{exercise}

The function

\begin{exercise}
Prove that the set of multiples of ten is countable.
\begin{answer}
Call the set $T=\set{10k\suchthat k\in\N}$.
The function $\map{f}{\N}{T}$ given by $f(n)=10n$ is a correspondence.
It is one-to-one because $f(n)=f(\hat{n})$ implies that $10n=10\hat{n}$,
and so $n=\hat{n}$.
It is onto because by definition any member of $T$ has the form $10k$ 
for some~$k\in\N$, and so is the image under~$f$ of~$k$.
\end{answer}
\end{exercise}

\begin{exercise}  \label{exer:StrictlyIncIMpliesOneToOne}
Let $E\subseteq\R$.
A function $\map{f}{E}{\R}$ 
is \definend{strictly increasing} if $x<\hat{x}$ implies that
$f(x)<f(\hat{x})$.
Prove that any strictly increasing function 
is one-to-one;
it is therefore a correspondence between its domain and
its range.
(The same applies if the function is strictly decreasing.)
Does this hold for $E\subseteq\N$?
\begin{answer}
To get a contradiction suppose that $f$ is not one-to-one.
Then there are $x,\hat{x}\in E$ such that
$f(x)=f(\hat{x})$ but $x\neq\hat{x}$.
With $x\neq\hat{x}$, one or the other is smaller; without loss of generality
suppose $x<\hat{x}$.
That gives $x<\hat{x}$ but $f(x)=f(\hat{x})$, which is the desired 
contradiction.  

Yes, the same argument works for $E\subseteq\N$.
\end{answer}
\end{exercise}

\begin{exercise} \label{exer:FiniteSetsSamSizeIffCorres}
We prove that for finite sets $D$ and~$C$, 
if there is a correspondence~$\map{f}{D}{C}$
then the two have the same number of elements.
Recall that $\sizeof{S}$, the cardinality of the set~$S$,
is the number of elements in~$S$.
\begin{exparts}
  \item Prove that if $f$ is one-to-one then $\sizeof{C} \geq \sizeof{D}$.
  \item Prove that if $f$ is onto then $\sizeof{C} \leq \sizeof{D}$.
\end{exparts}
\begin{answer}
\begin{exparts}
\item   Assume that $\map{f}{D}{C}$ is one-to-one.
  We will do induction on the number of elements in~$D$.
  The base step is that~$\sizeof{D}=0$.
  The codomain cannot have fewer elements than this
  so~$\sizeof{C} \geq \sizeof{D}$ holds in this case.

  For the inductive step assume that the statement is true when 
  $\sizeof{D}=0$, 
  \ldots, $\sizeof{D}=k$ and let~$D$ be a set with~$\sizeof{D}=k+1$.
  Pick some $d\in D$ and consider 
  $\hat{D}=D-\set{d}$ (because this is the $k+1$ case, there is at least
  one such element).
  The inductive hypothesis applies to $\hat{D}$ so that 
  the number of elements in the range of the restriction map 
  $\map{\hat{f}}{\hat{D}}{\range(\hat{f})}$
  is at least as great as the number of elements in the domain of that map
  $\sizeof{\range(\hat{f})} \geq \sizeof{\hat{D}}$.

  Now extend to~$D$ and the map~$\map{f}{D}{C}$.
  The set~$D$ has one element more than the set~$\hat{D}$.
  Because~$f$ is one-to-one, the value~$f(d)$ is not in 
  the range of the restriction map~$\range(\hat{f})$.
  Thus $\range(f)$ is one element larger than
  $\sizeof{\range(\hat{f})}$.
  Therefore $\sizeof{C} \geq \sizeof{D}$.      

\item   Assume that $\map{f}{D}{C}$ is onto.
  We do induction on the number of elements in
  the domain~$D$.
  The base step is that~$D$ has no elements, so $D=\emptyset$.
  The only function with an empty domain is the function whose graph is 
  empty. 
  This function is onto so the codomain~$C$ is also empty 
  (otherwise there would be an element of the codomain with no inverse
  image).

  For the inductive step assume that the statement is true when $\sizeof{D}=0$, 
  $\sizeof{D}=1$, \ldots, $\sizeof{D}=k$ and consider 
  the~$\sizeof{D}=k+1$ case.
  Pick some $d_0\in D$ and consider 
  $\hat{D}=D-\set{d_0}$ (because this is the $k+1$ case there is at least
  one such element in~$D$).

  There are two cases:
  whether the codomain element $f(d_0)$ is also the image of another domain
  element, some $d\in\hat{D}$, or else it is not.
  In the first case the restriction $\hat{f}$ is onto
  and so the inductive hypothesis applies, giving that 
  $\sizeof{C}\leq \sizeof{\hat{D}}<\sizeof{D}$.

  In the other case, that $d_0$ is the only element of~$D$ associated 
  by~$f$ with the codomain element~$f(d_0)$, let $\hat{C}=C-\set{f(d_0)}$.
  The restriction map~$\map{\hat{f}}{\hat{D}}{\hat{C}}$ is clearly onto,
  so the inductive hypothesis applies: $\sizeof{\hat{C}}\leq \sizeof{\hat{D}}$.
  Therefore $\sizeof{\hat{C}}+1=\sizeof{C}\leq \sizeof{D}=\sizeof{\hat{D}}+1$.
\end{exparts}
\end{answer}
\end{exercise}

\section{Diagonalization}
Cantor's definition of cardinality led us to produce  
correspondences.
We now introduce a powerful technique that can do the opposite, that
can show no correspondence exists.
We will approach the first question that we will
address with this new technique by giving it
an evocative framing.


\subsection{Hilbert's Hotel} \label{subsection:HilbertsHotel}
\margingraphic{.18\textwidth}{background/hotel.jpg}{\label{fig:hotel}\href{http://en.wikipedia.org/wiki/Ryugyong_Hotel}{A hotel with lots of empty rooms}}   % http://upload.wikimedia.org/wikipedia/commons/6/6b/Ryugyong_Hotel_-_August_27%2C_2011_%28Cropped%29.jpg
The prior section describes how infinite 
sets can be equinumerous, even though one may seem in some sense
smaller than the other.
These lessons are brought out in a memorable 
mathematical fable.

\citetext{Once unon a time}{The fable is due to 
David Hilbert in 1924.  
It was popularized by George Gamow in 
\textit{One, Two, Three \ldots{} Infinity}.  \autocite{Kragh}.}
there was an infinite hotel.  
The rooms were 
numbered $0$, $1$, \ldots, naturally.
One day, every room was occupied when 
someone new came. 
Could the hotel accomodate?
The desk clerk hit on the idea of moving each guest up a room, that is,
moving the guest in room~$n$ to room~$n+1$. 
With that, room~$0$ is empty.
So this hotel always had space for a new person, 
or any finite number of new people.

Next came a bus with infinitely many people $p_0, p_1,\ \ldots\ $.
Again the clerk had an idea:~move each guest to a room with twice the number, 
putting the guest from room~$n$ into room~$2n$.
Now the odd-numbered rooms are empty 
so everyone has a room.

Just then a convoy of buses pulled in, 
infinitely many of them,
each with infinitely many people.
\begin{equation*}
  B_0=\set{p_{0,0},\, p_{0,1},\, \ldots\,},
  \quad
  B_1=\set{p_{1,0},\, p_{1,1},\, \ldots\,},
  \quad
  \ldots
\end{equation*}
By now the spirit of the thing was clear:
move each guest to a new room with twice the number, and 
the new people go into the odd-numbered rooms, in the breadth-first order
$p_{0,0}$, $p_{1,0}$, $p_{0,1}$, $p_{2,0}$ \ldots{}
of \cref{exam:NCrossN}.  

After this experience the clerk could be forgiven for thinking
that there is always room in the infinite hotel\Dash
that with a sufficiently clever method it can fit any set of new guests at all.
Restated, the Hilbert's Hotel story makes natural the guess 
that all infinite sets have the same cardinality. 
Despite its naturalness, though, the guess is wrong.
We will next see that there are sets with so many members that they 
cannot all fit.\footnote{Alas, 
the infinite hotel does not now exist.
The story goes that  
the guest in room~$0$ 
said that the guest from room~$1$ would cover both of their bills.
The guest from room~$1$ said yes, but in addition
the guest from room~$2$ had agreed 
to pay for all three rooms, $0$--$2$.
Room~$2$ said that room~$3$ would pay, etc.
So Hilbert's hotel made no money despite having infinitely many rooms,
or perhaps because of it.}





\subsection{Diagonalization}
One set so large that it is not countable, 
a set for which no correspondence exists with~$\N$,
is the set of real numbers,~$\R$.

\begin{theorem}  \label{th:RealsNotCountable}
There is no onto map $\map{f}{\N}{\R}$. 
Hence, the set of reals is not countable.
\end{theorem}

This result is important but so is the technique we will use to prove it.
The proof is so short that a reader can miss the intuition behind it,
so we pause to develop this intuition.
The table below illustrates a function $\map{f}{\N}{\R}$, 
listing some inputs and outputs,
with the outputs aligned on the decimal point. 
\begin{equation*} \setlength{\arraycolsep}{0.75\arraycolsep}
  \begin{array}{c|r@{\hspace*{.35em}.\hspace*{.35em}}ccccccc@{\hspace*{1em}\ldots\;}}
    \multicolumn{1}{c}{\text{\small $n$\hspace*{0.25em}}} 
    &\multicolumn{8}{c}{\text{\hspace*{-1.00em}\small\tabulartext{Decimal expansion of $f(n)$}\ }}  \\ 
   \cline{1-9}
   \rule{0em}{2.15ex}% bit more vertical room 
   0  &4   &3  &1  &2  &7  &7  &0  &4  \\  
   1  &12  &0  &1  &0  &0  &0  &0  &0  \\  
   2  &1   &4  &1  &4  &1  &5  &9  &2  \\  
   3  &-20  &9  &1  &9  &5  &9  &1  &9  \\  
   4  &  0 &1  &0  &1  &0  &0  &1  &0  \\
   5  &-0  &6   &2  &5  &5  &4  &1  &8  \\[-.5ex]
   \multicolumn{1}{c}{\vdotswithin{$0$}} 
    &\multicolumn{4}{c}{\vdotswithin{$1$}}  
  \end{array}
  \label{ex:DiagonalizationTable}
\end{equation*}
We will show that this function is not onto.
We will do that by producing a number $z\in\R$ that does not equal 
any of the outputs, any of the $f(n)$'s.

Ignore what is to the left of the decimal point.
To its right, go down the diagonal:
take the digits $3$, $1$, $4$, $5$, $0$, $1$ \ldots{}\,.
Construct~$z$ by making its first decimal place 
something other than~$3$, 
making its second decimal place something other than~$1$, etc.
To be specific: if the diagonal digit is a $1$ then~$z$ gets 
a~$2$ in that decimal place, and otherwise~$z$ gets a~$1$ there. 
Thus, in this example $z=0.121112\ldots$\,.

By construction, $z$ differs from the number in the first row,
$z\neq f(0)$, because they differ in the first decimal place.
Similarly,~$z\neq f(1)$ because they differ in the second 
place.
In this way $z$ does not equal any of the~$f(n)$. 
Thus $f$ is not onto.

(In this argument we must skirt a technicality, that
some real numbers have two different decimal representations.
For instance, $1.0000\ldots=0.999\ldots$ 
because the two differ by less than $0.1$, less than~$0.01$, etc.
This is a potential snag because 
it means that showing $z$'s 
representation differs from the representation of a number on the list
does not show that~$z$ is unequal to that number.
However, for decimals this dual representation happens only when one of the 
representations ends in $0$'s while the other ends in~$9$'s.
For this reason
we build~$z$ using only $1$'s and $2$'s.)

\citetext{This technique}{The argument just sketched is often called Cantor's 
diagonal proof, although it was not Cantor's original argument for the result, 
and although the argument style is not due to Cantor but instead to 
Paul du~Bois-Reymond.  
The fact that scientific results are often attributed to people who
are not their 
inventor is \protect\textit{Stigler's law of eponymy}, because it wasn't 
invented by Stigler (who attributes it to Merton). 
In mathematics this effect is called \protect\textit{Boyer's Law}, who 
didn't invent it either. \autocite{wiki:StiglersLaw}}
is \definend{diagonalization}.
It is critical for our work.

\begin{proof}
Consider a map $\map{f}{\N}{\R}$.
We will show that $f$ is not onto.

Write $f(i)[i]$ for the $i$-th decimal digit of $f(i)$ 
(if $f(i)$ is a number with two decimal representations then we use the 
one ending in $0$'s).
Let $g$ be the map on the decimal digits $\set{0,\ldots,9}$ given by:
$g(j)=2$ if $j$ is~$1$, and $g(j)=1$ otherwise.

Now let~$z$ be the real number that is~$0$ to the left of its decimal point
and that has the $i$-th decimal digit
$g(f(i)[i])$. 
Then $z\neq f(i)$ for all~$i$, because $z[i]\neq f(i)[i]$. 
So $f$ is not onto. 
\end{proof}


\begin{definition}
An infinite set that is not countable is \definend{uncountable}.  
\end{definition}

We next define when one set has more elements than another.
The intuition comes from trying 
to make a correspondence 
between the two finite sets $\set{0,1,2}$ and $\set{0,1,2,3}$. 
There are just too many elements in the codomain
for any map to cover them all.
The best we can do is 
something like this, which is one-to-one 
but is not a correspondence because it is not onto. 
\begin{center}
    \includegraphics{background/asy/maps/maps02.pdf}
\end{center}

\begin{definition}
The set $S$ has \definend{cardinality less than or equal to}
that of the set~$T$,    
denoted $\sizeof{S}\leq \sizeof{T}$,
if there is a one-to-one function from $S$ to~$T$.
\end{definition}

For example, there is a one-to-one function from $\N$ to $\R$,
namely the inclusion map that sends $n\in\N$ to itself~$n\in\R$.
However the two do not have equal cardinality 
so no function from $\N$ to~$\R$ is onto.
Another example is that there is a one-to-one function from $\N$ to $\Z$.
But in this case there is a one-to-one functin that is also onto, as
shown by \cref{ex:ZIsCountable}.

The wording of that definition implies that if both 
$\sizeof{S}\leq \sizeof{T}$ and 
$\sizeof{T}\leq \sizeof{S}$ then $\sizeof{S}=\sizeof{T}$.
That is true, but the proof is beyond our scope;
see~\cref{exer:SchroderBernstein}. 

For the next result, 
recall that a set's \definend{characteristic function} $\charfcn{S}$ 
is the boolean function determining membership:
$\charfcn{S}(s)=1$ if $s\in S$ and $\charfcn{S}(s)=0$ if $s\notin S$.
Thus, for the set of two letters $S=\set{\str{a},\str{c}}$,
the characteristic function 
with domain $\Sigma=\set{\str{a},\ldots, \str{z}}$ 
is
$\charfcn{S}(\str{a})=1$
$\charfcn{S}(\str{b})=0$,
$\charfcn{S}(\str{c})=1$, 
$\charfcn{S}(\str{d})=0$,
$\ldots$\,
$\charfcn{S}(\str{z})=0$. 
Recall also that the \definend{power set}~$\powerset(S)$ 
is the collection of subsets of $S$ and so
$
  \powerset(S)=\set{\emptyset, \set{\str{a}}, \set{\str{c}},
                          \set{\str{a},\str{c}} }
$.

\begin{theorem}[Cantor's Theorem]
Each set's cardinality is strictly less than that of its power set.    
\end{theorem}

% Thus, given a set, 
% we can produce another one whose cardinality is strictly 
% greater\Dash there's always a
% bigger set.

We first illustrate the proof.
The easy half is 
producing a function from a set $S$ to $\powerset(S)$ that is one-to-one:
just map $s\in S$ to the singleton set $\set{s}$.

The hard half is
showing that no map from $S$ to $\powerset(S)$ is onto.
Consider for example the set $S=\set{\str{a},\str{b},\str{c}}$ 
and this function $\map{f}{S}{\powerset(S)}$.
\begin{equation*}
  \str{a}\mapsunder{f}\set{\str{b},\str{c}} 
  \qquad
  \str{b}\mapsunder{f}\set{\str{b}}
  \qquad
  \str{c}\mapsunder{f}\set{\str{a},\str{b},\str{c}}
\end{equation*}
In the table below the three rows list the 
values of the three characteristic functions 
of the output sets
$\map{\charfcn{f(\str{a})}}{S}{\set{0,1}}$, 
$\map{\charfcn{f(\str{b})}}{S}{\set{0,1}}$, 
and $\map{\charfcn{f(\str{c})}}{S}{\set{0,1}}$.
%  of the
% three output sets $f(\str{a})$, $f(\str{b})$, $f(\str{c})$.
\begin{center}
  \begin{tabular}{c|c|ccc}
    \multicolumn{1}{c}{$s\in S$}
       &\multicolumn{1}{c}{$f(s)$}
       &$\charfcn{f(s)}(\str{a})$  
       &$\charfcn{f(s)}(\str{b})$   
       &$\charfcn{f(s)}(\str{c})$  
    \\[.5ex] \hline \rule{0em}{2ex}
    $\str{a}$ &$\set{\str{b},\str{c}}$          &$0$ &$1$ &$1$  \\ 
    $\str{b}$ &$\set{\str{b}}$                  &$0$ &$1$ &$0$  \\ 
    $\str{c}$ &$\set{\str{a},\str{b},\str{c}}$  &$1$ &$1$ &$1$  
  \end{tabular}
\end{center}
To produce a subset of~$S$ that is not one of the three shown above, 
diagonalize:  
go down the diagonal and flip the bits from $0$ to~$1$, and
from $1$ to~$0$.
The diagonal shown is \str{011} so we switch to \str{100},
which is the characteristic function of the set 
$R=\set{\str{a}}$.
This set is
not $f(a)$ because it differs on the input~$\str{a}$, 
it is not $f(b)$ because it differs on~$\str{b}$,
and it is not $f(c)$ because it differs on~$\str{c}$.

\begin{proof}
One half is easy:
consider the map $\map{\iota}{S}{\powerset(S)}$
given by $\iota(s)=\{s\}$.
Clearly it
is one-to-one, so the cardinality of $S$
is less than or equal to the cardinality of $\powerset(S)$.

For the other half,
to show that no map from a set to its power set is onto, 
fix any~$\map{f}{S}{\powerset(S)}$ and consider 
this element of $\powerset(S)$ (this is where we flip the bits).
\begin{equation*}
  R=\set{s \suchthat s\notin f(s)}
  % \tag{$*$}
\end{equation*}
We will show that no member of the domain maps to~$R$,
and thus $f$ is not onto.

Suppose that there exists $\hat{s}\in S$ such that $f(\hat{s})=R$.
Consider whether $\hat{s}$ is an element of~$R$.
We have that $\hat{s}\in R$ if and only if 
$\hat{s}\in\set{s\suchthat s\notin f(s)}$.
By definition of membership, that holds if and only if
$\hat{s}\notin f(\hat{s})$, which 
holds if and only if $\hat{s}\notin R$.
This contradiction means that no such $\hat{s}$ exists.
\end{proof}

\begin{corollary} \label{cor:FcnsNNGreaterFcnsN}
The cardinality of the set~$\N$ is strictly less than the cardinality of 
the set of all natural number functions $\map{f}{\N}{\N}$.  
\end{corollary}

\begin{proof}
Let~$F$ be the set
of functions~$\map{f}{\N}{\N}$.
There is a natural one-to-one map from $\powerset(\N)$ to~$F$:
associate each subset $S\subseteq\N$ with its characteristic function 
$\map{\charfcn{S}}{\N}{\N}$.
Therefore~$\sizeof{\N}<\sizeof{\powerset(\N)}\leq\sizeof{F}$.
\end{proof}

This is a game of Musical Chairs,
with countably many chairs
$P_0,P_1,\ldots$\,.
By the prior result there are just too many functions $\map{f}{\N}{\N}$
to fit in the chairs.  
Some function is \citetext{left without a chair}{%
This is a Pigeonhole Principle argument.}.

In the next section we will show that there are countably many 
Turing machines.
With that, we are thinking about fitting the functions
$\map{f}{\N}{\N}$ into chairs that come one for each machine,
$\TM_0,\TM_1,\ldots$\,.
Here also there will be a function without a chair\Dash
the cardinality of the set of functions $\map{f}{\N}{\N}$
is greater than the cardinality 
of the set of Turing machines.

This is an epochal result:~in the light of Church's Thesis we see it
as the proof that there are functions not computed by
any program,
there are jobs no computer can do.

applied to the rationals?

\end{exercise}

\begin{exercise} \label{exer:SchroderBernstein}
The \definend{Schröder–Bernstein theorem} is that if
$\sizeof{S}\leq \sizeof{T}$ and $\sizeof{T}\leq \sizeof{S}$ 
then $\sizeof{S}=\sizeof{T}$.
That is, if there is a one-to-one function $\map{f}{S}{T}$ and a
one-to-one function $\map{g}{T}{S}$ then there is a correspondence, a function
$\map{h}{S}{T}$ that is both one-to-one and onto.
We prove this theorem.
The proof depends on finding chains of images:
for any $s\in S$ we form the associated chain 
by iterating application of the
two functions both to the right 
and to the left. 
\begin{equation*}
  \ldots,\,f^{-1}(g^{-1}(s)),\,g^{-1}(s),\,s,\,f(s),\,g(f(s)),\,f(g(f(s))),\, \ldots
  % \tag{$*$}
\end{equation*}
The chain associated with $t\in T$ is defined similarly. 
For instance, let $S=\set{0,1,2}$ and $T=\set{\str{a},\str{b},\str{c}}$
(where the elements of $T$ are characters, not variables).
Let these be $\map{f}{S}{T}$ and $\map{g}{T}{S}$.
\begin{center}
  \begin{tabular}{c|c}
    $s$    &\multicolumn{1}{c}{$f(s)$}  \\ \hline
    $0$    &$\str{b}$  \\
    $1$    &$\str{c}$  \\
    $2$    &$\str{a}$  
  \end{tabular}
  \qquad
  \vcenteredhbox{\includegraphics{background/asy/maps/maps03.pdf}}
  \qquad
  \begin{tabular}{c|c}
    $t$       &\multicolumn{1}{c}{$g(t)$}  \\ \hline
    $\str{a}$ &$0$   \\
    $\str{b}$ &$1$    \\
    $\str{c}$ &$2$     
  \end{tabular}
\end{center}
Then starting at $0\in S$ and iterating
shows that there is a single chain and it is cyclic:
$\,\cdots\,0\mapsto\str{b}\mapsto 1\mapsto\str{c}\mapsto 2\mapsto\str{a}\mapsto 0\,\cdots$\,.
\begin{exparts}
\item 
  Consider $S=\set{0,1,2,3}$ and $T=\set{\str{a},\str{b},\str{c},\str{d}}$.
  Let $f$ associate $0\mapsto\str{a}$, $1\mapsto\str{b}$, $2\mapsto\str{d}$
  and $3\mapsto\str{c}$.
  Let $g$ associate $\str{a}\mapsto 0$, $\str{b}\mapsto 1$, $\str{c}\mapsto 4$
  and $\str{d}\mapsto 3$.
  Check that these maps are one-to-one.
  List the chain associated with each element of $S$ and the 
  chain associated with each element of $T$.
\item For infinite sets a chain can have a first element or a last element.  
   Let $S$ be the even numbers and let $T$ be the odds.
   Let $\map{f}{S}{T}$ be $f(x)=x+1$ and let $\map{g}{T}{S}$ be $g(x)=x+1$.
   Show each map is one-to-one.
   Show there is a single chain and that it has a first element, an 
   element without any preimage.
\item For the same sets as in the prior item, produce maps leading to a 
   single chain, with a last element.
\item Assume $S$ and $T$ are disjoint and that $\map{f}{S}{T}$
  and $\map{g}{T}{S}$ are one-to-one.
  Show that every element of either set is in a unique chain, 
  and that each chain is of one of four kinds: (i)~those that
  repeat after some number of terms
  (ii)~those that continue infinitely in both directions
  (iii)~those that continue infinitely to the right but stop on the left
  at some element of~$S$, 
  and (iv)~those that continue infinitely to the right but stop on the left
  at some element of~$T$.
\item Show that for any chain the function below 
  is a correspondence between the 
  chain's elements from~$S$ and its elements from~$T$.
  \begin{equation*}
    h(s)=
    \begin{cases}
      f(s) &\case{if $s$ is in a sequence of type~(i), (ii), or~(iii)}  \\
      g^{-1}(s) &\case{if $s$ is in a sequence of type~(iv)}
    \end{cases}
  \end{equation*}
\item Show that we can assume without loss of generality that $S$ and
  $T$ are disjoint.
\end{exparts}

\end{exercise}
\end{exercises}

\begin{definition}
A \definend{numbering} is a function that assigns to each Turing machine
a natural number.  
For any Turing machine, the corresponding number is its
\definend{index number}, or \definend{G\"odel number}, 
or \definend{description number}.
For the machine with index~$e\in\N$ we write \definend{$\TM_e$}.
For the function computed by $\TM_e$ we write~\definend{$\phi_e$}. 

A numbering is \definend{acceptable} if
(1)~it is effective: there is a program that takes as input
the source of the Turing machine, the set of instructions,
and gives as output the associated number,
(2)~the set of numbers for which there is an associated machine is computable,
and (3)~there is an effective inverse that takes as input
a natural number and gives as output the associated Turing machine source. 
\end{definition}

Think of the machine's index as its designator, or name.
We will refer to it frequently, for instance as
``the $e$-th Turing machine.''

The exact numbering that we use 
\citetext{doesn't matter much}{For the precise meaning of ``much'' 
see \autocite{Rogers58}.} as long as it is acceptable, so 
for the rest of the book we will just fix one.
That is, we can take the numbering to be \codeinline{godel} and its
inverse to be \codeinline{machine},
although we won't ever need the details of those. 
The point is that because the numbering is acceptable, 
by conditions~(1) and~(3) the index is source-equivalent\Dash 
we can go effectively from the index to the machine source or
from the source to the machine index.

\subsection{Universal Turing machine}
A pattern in technology is for jobs done in hardware to migrate to software.
The classic case is weaving.
\begin{center}
  % http://commons.wikimedia.org/wiki/File:Loomwork.jpg
  \includegraphics[width=.33\textwidth]{background/loom.jpg}
  \hspace*{2em}
  % http://commons.wikimedia.org/wiki/File:Deutsches_Technikmuseum_Berlin_February_2008_0013.JPG 
  \includegraphics[width=.33\textwidth]{background/jaquardpunchedcards.jpg}
\end{center}
Weaving by hand, as the loom operator on the left is doing,
is intricate and slow.
We can make a machine to reproduce her pattern but what if we want a 
pattern that is different? 
In 1801 
\href{https://en.wikipedia.org/wiki/Jacquard_weaving}{J~Jacquard} 
built a loom like the one on the right, controlled by 
holes punched in paper cards
(it weaves with hooks whose positions, raised or lowered, are controlled by 
the holes in the cards).
Getting a different pattern only requires 
swapping out the cards, not the entire loom.

Turing introduced the analog for computing devices.

\begin{theorem}[Turing, 1936]
There is a Turing machine that when
given the input $\sequence{e,x}$ will have the same   
output behavior as does $\TM_e$ on input~$x$.
\end{theorem}

We simulate Turing machines
with a Scheme program to practice working with them.
Thus, we know that Scheme can simulate Turing machines. 
This theorem asserts that Turing machines can simulate Turing machines\Dash
there is a single 
Turing machine that can act like any Turing machine at all.
This is a \definend{Universal Turing Machine}.
We denote such a machine with~$\UTM$.

\margingraphic{0.2\textwidth}{background/snake.png}{\label{fig:ouroboros}\href{https://commons.wikimedia.org/w/index.php?curid=36915535}{An ouroboros, a snake swallowing its own tail}}
A universal machine may seem to present a 
chicken and egg problem:~how can we give Turing machines as input to 
Turing machines?
In particular, the machine 
of the theorem has some index~$e$,
and the theorem seems to allow this machine possibly being 
given~$\sequence{e,x}$, or even $\sequence{e,e}$\Dash
won't giving a machine to itself lead to infinite regress?

The resolution of this problem is that
we don't give a machine to itself;
instead, the machine gets a representation of itself.
We run Turing machines by putting symbols on the tape as data
and pressing Start.
So if we show how to represent something with symbols on tape,
including representing a Turing machine on a tape, then 
we've shown how to get a machine to take that representation as input.

First, a technical point.
Turing machines have a tape alphabet.
So we have to put on the tape input that the machine is defined as able to
take.
But the definition of Turing machine has every machine takes at 
least two symbols, one of which is blank, so if we can do the 
representation in binary then we are OK. 

Now, here is one way that we can represent a Turing machine on a tape.
(We use \str{1} for the second symbol.)
Encode each four-tuple as a sequence of four blocks 
of \str{1}'s, separated by single~\str{B}'s.
The first block encodes the current-state number using the unary 
representation, where the number~$n$ is represented by 
$n+1$-many \str{1}'s (use an extra \str{1} so that $0$'s representation is 
nonempty).
The second block encodes the current symbol, 
with \str{1} representing the symbol blank
and \str{11} representing the symbol one.
The third block gives the next-state number, also in unary.
The fourth block represents the action performed: encode
writing a blank symbol as \str{1}, encode writing a one as~\str{11}, 
encode a move to the left~$L$ as \str{111}, and a move to the right~$R$ 
as \str{1111}.
Now to encode a complete machine, a set of four-tuples, 
put tuples on the tape in any order but separated by two blanks~\str{BB}.
Finally, separate the description of the machine from 
the input with three blanks~\str{BBB}.

That encoding of a Turing machine will do as input to any other machine,
provided the second one can accept \str{1}'s (and \str{B}'s, but our
definition has all Turing machines including blanks as part of the 
tape alphabet).

So, for any Turing machine, we could 
put its representation on the tape of another Turing machine 
(that accepts \str{1}'s),
or on its own tape (if it accepts \str{1}'s), and press \texttt{Start}.
If, say, the machine that we just started is an input doubler 
then the output may well not have any apparent 
sensible connection to the fact that the input represents a Turing machine.
Nonetheless, feeding a Turing machine as input to another Turing machine, 
or to itself, is perfectly possible, in that what we input is the 
representation of the machine.

Now that we know representation is possible, what remains is to see that 
there are 
universal machines, ones that can act like the thing that is represented.
With such a device, 
changing its behavior would only involve putting
new stuff on the tape\Dash this is like the punched cards, which
alter the behavior of the machine without any hardware patch chords.
In Turing's time, showing that $\UTM$'s exist required
a detailed analysis so he exhibited such a machine.
Here, we start by appealing to the intuition that we have from 
everyday computing experience.

Church's Thesis allows us to take this program

This program may take input, a string of $0$'s and $1$'s, which we can

\subsection{Uniformity}
We claim that there are functions no program can do.
Can't we just put out the numbers $0$ and $1$?  
What's to stop us?

Of course, being able to print out the digits does not make a program
able to print the digits of $\pi$.
Willy-nilly versus uniform is the difference between scissors and surgery.

\begin{example} \label{ex:NineInPi}
Consider this problem: given a number $n$, 
decide whether somewhere in the decimal expansion of~$\pi=3.14159\ldots{}$ 
there is a sequence of 
\citetext{$n$~consecutive nines}{At the $762$-nd decimal point there are 
$6$ nines in a row.  
This is call the Feynman point; see 
\protect\url{https://en.wikipedia.org/wiki/Feynman_point}.
Most experts guess that for any~$n$ the decimal 
expansion contains a sequence of 
$n$ consecutive nines but no one has proved or disproved that.}.    
There are two possibilities:
either for all numbers such a sequence exists, or else there is some
$n_0$ where the sequence exists for numbers less or equal to~$n_0$ and no such
sequence exists for numbers larger than that.

Thus, the problem is solvable by one of these two programs.
\begin{center}
\vspace*{-4ex}
\begin{minipage}[t]{0.4\linewidth}%
\begin{lstlisting}
read n
print 1
\end{lstlisting}%
\end{minipage}%
\hspace*{2em}
\begin{minipage}[t]{0.4\linewidth}%
\begin{lstlisting}
read n
if n < n0:
    print 1
else:
    print 0
\end{lstlisting}%
\end{minipage}%
\vspace*{-2ex}
\end{center}
Although we have just shown this problem is mechanically solvable,
nonetheless we do not know what the solution is.
In short, there is a difference between defining this function
\begin{equation*}
  f(n)=
  \begin{cases}
    1 &\case{if there are $n$ consecutive $9$'s}  \\
    0 &\case{otherwise}
  \end{cases}
\end{equation*}
and giving an algorithm to compute it.

This is like the paradox in Physics of 
\citetext{Schr\"odinger's cat}{See \protect\url{https://en.wikipedia.org/wiki/Schr\%C3\%B6dinger's_cat}.} 
in that if only we could somehow peek 
then we'd see which one of the two is the answer, but as it stands
we just don't know.
Nevertheless, the problem is solvable.
\end{example}



\subsection{Parametrization}
% \subsection{$\mathbf{s}$-$\mathbf{m}$-$\mathbf{n}$ theorem}
% ====== S-m-n, uniformity
We can understand universality to be that there is a computable
function $\map{F}{\N^2}{\N}$ such that
$F(e,x)=\phi_e(x)$.
There, the letter~$e$ goes from the function argument to an index.
We now generalize this observation.

Consider a two-input program $\TM_e(x,y)$.
Freezing the first argument, that is, locking $x=a$ for some $a\in\N$,
gives a one-input program $\TM{Q}_a(y)=\TM_e(a,y)$.
For example, starting with the program
\begin{lstlisting}
  P(x,y)
\end{lstlisting}
and fixing the first input at $a=7$ gives a one-input program.
\begin{lstlisting}
  Q_7(y)  
\end{lstlisting}
This is \definend{partial application}.
Obviously the second program is related to the first.
The next result is that the index of the second program is computable from the
first.

\begin{theorem}[Parameter theorem]
For every $m,n\in\N$
there is a computable function $\map{s}{\N^{1+m}}{\N}$ with this behavior:
where $m+n$-ary function computed by $\TM_e$ is
$\TMfcn_e(x_0,\ldots,x_{m-1},x_m,\ldots,x_{m+n-1})$,
freezing the initial $m$~variables at $a_0,\ldots,a_{m-1}\in\N$
gives the function computed by $\TM_{s(e,a_0,\ldots,a_{m-1})}$.
\end{theorem}

\begin{proof}
We must create $s$ to be effective, to input 
an index~$e$ and an $m$-tuple $x_0,\ldots,x_{m-1}$,
and to output the index of a machine~$\hat{\TM}$.
This machine~$\hat{\TM}$, when given the input $x_m,\ldots,x_{m+n-1}$,
will return
$\TMfcn_e(x_0,\ldots,x_{m-1},x_m,\ldots,x_{m+n-1})$.

Basically, $s$ constructs the instructions for~$\hat{\TM}$.
We know how to get from the instruction set to the index,
using Cantor's encoding, so then we are done.
The flowchart for $s$ is on the left below.
\begin{center}
  \vcenteredhbox{\includegraphics{background/asy/flowcharts/flowcharts00.pdf}}
  \hspace{3em}
  \vcenteredhbox{\includegraphics{background/asy/flowcharts/flowcharts01.pdf}}
\end{center}
The flowchart for $\hat{\TM}$, the Turing machine that $s$ constructs,
is on the right.
Before considering that, recall our convention for Turing machine input.
It is encoded in unary, with the number~$k$ represented by
a string of $k$-many \str{1}'s.
Multiple inputs are separated with a single blank.
And when the machine is started, the head should be under the input's
left-most \str{1}.

The machine $\hat{\TM}$ does not start by reading
its inputs $x_m,\ldots,x_{m+n-1}$.
Instead, it moves left and puts $x_0,\ldots,x_{m-1}$ on the tape,
in unary and separated by blanks.
Thus, 
when this phase is done the machine will have $x_0,\ldots,x_{m+n-1}$ on the
tape, in unary and separated by blanks.
Next move the I/O head until it is on the leftmost \str{1}
of the $x_0$.
Finally, turn control
over to Turing machine~$P_e$ (using universality),
which will run on that input list.
\end{proof}

The following Scheme code implements $s_{1,1}$.
(The \lstinline!gensym! function produces a symbol that does not appear
elsewhere in the program.)
% https://en.wikipedia.org/wiki/Smn_theorem
\begin{lstlisting}

   (let ((y (gensym)))
     (list 'lambda (list y) (list f x y))))
\end{lstlisting}

we can fix the first variable~\lstinline!x! to have the value~$3$ with 
the invocation \lstinline!(s_1_1 '(lambda (x0 x1) (+ x0 x1)) 3)!, which  
evaluates to the one-input function 
\lstinline!(lambda (g42) ((lambda (x0 x1) (+ x0 x1)) 3 g42))! that 
adds~$3$ to its argument.

\section{The \HP}
We've showed that
there are functions that are not mechanically computable.
We gave a counting argument:~there are countably many Turing machines but 
uncountably many functions and so there are functions without an
associated machine.
While knowing what's true is a step forward,
our taste is to prefer to construct a specific a function for which there
is no associated Turing machine.
We now exhibit such a function.



\subsection{Definition}
The natural approach is to go through 
Cantor's Theorem and effectivize it,
to see how much of the proof we can express as a construction.

Consider an illustrative table adapted from the discussion of
Cantor's Theorem, on 
\cpageref{ex:DiagonalizationTable}.
It imagines that the rows are computable functions and 
the columns are inputs.
For instance, this table lists $\phi_1(3)=0$.
\begin{center} \small \setlength{\arraycolsep}{0.75\arraycolsep}
  \begin{tabular}{r|ccccccc@{\hspace*{1em}$\ldots$}}
    \multicolumn{1}{r}{\ } 
    &\multicolumn{7}{c}{\text{\tabulartext{Input~$x$}}}  \\
     % \multicolumn{1}{c}{\text{\tabulartext{Function}}}
     \multicolumn{1}{c}{\ }
    &$0$ &$1$ &$2$ &$3$ &$4$ &$5$ &$6$ \\ 
   \cline{2-8}
   \rule{0em}{2.15ex}% bit more vertical room 
   $\phi_0$  &$3$  &$1$  &$2$  &$7$  &$7$  &$0$  &$4$  \\  
   $\phi_1$  &$0$  &$5$  &$0$  &$0$  &$0$  &$0$  &$0$  \\  
   $\phi_2$  &$1$  &$4$  &$1$  &$5$  &$9$  &$2$  &$6$  \\  
   $\phi_3$  &$9$  &$1$  &$9$  &$1$  &$9$  &$1$  &$9$  \\

   \multicolumn{1}{r}{$\vdotswithin{0}$} 
    &\multicolumn{6}{c}{$\vdotswithin{0}$}  
  \end{tabular}
  \hspace*{2em plus 0.75fil}
  \vcenteredhbox{\includegraphics{background/asy/hp/hp02.pdf}}
\end{center}
Diagonalize.
That is, consider the program and note that its output is not any of the 
table's rows.
That's a contradiction to the supposition that
the rows are all of the computable functions.

So what's the resolution?
Among the computable functions 
there must be one that on some input does not converge.
In particular this must happen on the table's diagonal\Dash there must be
some $e\in\N$ so that $\phi_e(e)\diverges$.
This makes the difficulty dissolve because for those input~$e$'s
in the flowchart, the program will never leave 
the middle box and so will never get to the contradictory output.
In brief, in the above table some of the entries must be up arrows, $\uparrow$.

\begin{definition}
  $\definend{K}=\set{e \suchthat \text{$\TM_e$ halts on input~$e$}}$
\end{definition}

\begin{problem}[Halting Problem]  \label{prob:HaltingProblem}
Given~$e\in\N$ determine whether Turing machine~$\TM_e$ halts on input~$e$,
that is, whether $\TMfcn_e(e)\converges$.
\end{problem}

Certainly for any $e\in\N$, either $\TMfcn_e(e)\converges$ or
$\TMfcn_e(e)\diverges$.
Thus there is a function giving $1$ in the first case and $0$ in the second.
The \HP{} is to find a Turing machine whose behavior is that function.
That is, the \HP{} is to produce a program 
$\computablefunction{halt\_checker}$ that acts as the characteristic
function of $K$, returning $1$ if $\TM_e$ halts on input~$e$ and
returning~$0$ otherwise.


\begin{theorem}[Unsolvability of the \HP]
The \HP{} is mechanically unsolvable.
\end{theorem}

\begin{proof}
Assume otherwise, that there is a Turing machine whose behavior is this.
\begin{equation*}
  K(e)=
  \computablefunction{halt\_checker}(e)=
  \begin{cases}
  1  &\case{if $\TMfcn_e(e)\converges$}  \\
  0  &\case{if $\TMfcn_e(e)\diverges$} 
  \end{cases}
\end{equation*}
Then the function below is also mechanically computable.
The flowchart illustrates $f$'s construction;
it uses $\computablefunction{halt\_checker}$ for the branch.
\begin{center}
\begin{minipage}{0.3\textwidth}
  \begin{equation*}
  f(e)=
    \begin{cases}
    0    &\case{if $\TMfcn_e(e)\diverges$}  \\
    \uparrow  &\case{if $\TMfcn_e(e)\converges$}
    \end{cases}
  \end{equation*}
\end{minipage}
\hspace{3em}
\vcenteredhbox{\includegraphics{background/asy/flowcharts/flowcharts02.pdf}}
\end{center}
(In the function's first case it doesn't matter
that $f(e)$ outputs~$0$, just that it converges.)
Since $f$ is mechanically computable it has an index.
Let that index be~$\hat{e}$, so that
$f(x)=\TMfcn_{\hat{e}}(x)$ for all inputs~$x$.

Now feed $f$ its own index\Dash consider $f(\hat{e})=\TMfcn_{\hat{e}}(\hat{e})$.
If it diverges then by the first clause in the definition of~$f$
we have $f(\hat{e})\converges$,
which contradicts that $f$~diverges.
If it converges then by $f$'s second clause 
we have $f(\hat{e})\diverges$, which is also impossible.
Since assuming that $f$ is mechanically computable is contradictory,
the function from which $f$ is constructed,
$\computablefunction{halt\_checker}$,
is also not mechanically computable.
\end{proof}






\subsection{Discussion}
The fact that the Halting Problem is unsolvable does not mean that 
we cannot tell if any program halts. 
This program obviously halts for every input.
\begin{lstlisting}
#;1> (define (prompt/read prompt)
--->     (display prompt)
--->     (read-line))
#;2> 
#;2> (+ 1
--->    (string->number (prompt/read "Enter n")))
Enter n---> 4
5  
\end{lstlisting}
Nor does the unsolvability of \HP{} mean we cannot tell if a program 
does not halt.
Consider this one.
\begin{lstlisting}
#;1> (define (f x)
--->   (+ 1 (f x)))
\end{lstlisting}
We have to interrupt it, or it would just keep going.
\begin{lstlisting}
#;2> (f 0)

	<eval>	  [f] (+ 1 (f x))
	<eval>	  [f] (f x)
	<eval>	  [f] (+ 1 (f x))
	<eval>	  [f] (f x)
	<eval>	  [f] (+ 1 (f x))
	<eval>	  [f] (f x)
	<eval>	  [f] (+ 1 (f x))

\end{lstlisting}

Instead, the unsolvability of the Halting Problem 
says that there is no single program that, for all~$e$, correctly computes 
in a finite time whether $\TM_e$ halts on input~$e$.

The ``finite time'' qualifier is there because we could just use a universal
Turing machine to simulate $\TM_e$ on~$e$, but if that machine failed to halt
then we would not find out in a finite time. 

The ``single program'' qualifier is there because for any index~$e$,
either $\TM_e$ halts on~$e$ or it does not.
That is, for any~$e$ one of these two programs
gives the right answer.
\begin{center}
% \vspace*{-4ex}
\vspace*{-\ht\strutbox}
\begin{minipage}[t]{0.4\linewidth}%
\begin{lstlisting}
read e
print 0
\end{lstlisting}%
\end{minipage}%
\hspace*{2em plus 0.5fil}
\begin{minipage}[t]{0.4\linewidth}%
\begin{lstlisting}
read e
print 1
\end{lstlisting}%
\end{minipage}%
% \vspace*{-2ex}
\end{center}
Thus, the unsolvability of the Halting Problem is about 
the non-existence of a single program that works across all
indices.
The \HP{} speaks to uniformity,
or rather, the impossibility of uniformity.




\subsection{Significance}  \label{subsec:Significance}
A beginning programming class can leave the 
impression that if a program doesn't halt then
it just has a bug, something fixable.
So the \HP{} could seem to be not very interesting. 
That impression is wrong.

Imagine 
a utility for programmers, $\computablefunction{always\_halt}$,
to patch non-halting programs.
After writing a program~$\TM$ we run it through the utility, which
modifies the source so that for any input where $\TM$ fails to halt,
the modified program will halt (and output $0$) but the utility
does not change any outputs where $\TM$ does halt.
That would cause the list of all programs to give rise to a 
list of total functions like the one in the Definition subsection,
and diagonalization leads to a contradiction.

So, the fact
that there are some indices and inputs for which the computation never halts
is essential to the nature of computation. 
There must be some computations that halt on all inputs, 
some that halt on no inputs, 
and some that \citetext{halt on some inputs but not on others}{A 
  Turing machine could fail to halt because it has an infinite loop.
  The Turing machine
  $\TM_0=\set{\tminstruction{0}{B}{B}{0},
    \tminstruction{0}{1}{1}{0}}$
  never halts, cycling forever in state $q_0$.
  We could patch this problem; we could write a program
  $\computablefunction{inf\_loop\_checker}$ that at each
  step checks whether a machine has ever before in this computation
  had the same configuration as it has now.
  This program will detect infinite loops like the prior one.
  
  However, note that there are machines that fail to halt but
  do not have loops, in the sense that they never repeat a configuration.
  One is $\TM_1=\set{\tminstruction{0}{B}{1}{1},
        \tminstruction{1}{1}{R}{0}}$
  which when started on a blank tape will endlessly move to the right,
  writing \str{1}'s.}.

That alone is enough to justify study of the \HP{} but we will give a 
second reason.
If $\computablefunction{halt\_checker}$ were a computable function
then we could solve many problems that we currently don't know how to solve. 
For instance, a natural number is \textit{perfect} if it is the 
sum of its proper positive divisors.
\margingraphicnomag*[l]{.425\textwidth}{background/asy/hp/hp00.pdf}
Thus $6$ is perfect because $6=1+2+3$.
Similarly, $28 = 1 + 2 + 4 + 7 + 14$ is perfect.
% and after that comes $496$ and~$8128$.
These were studied as far back as Euclid and
today we 
\citetext{understand the form of all even perfect numbers}{A 
number is an even perfect number if and only if it has the form 
$(2^p-1)\cdot 2^{p-1}$ where $2^p-1$ is prime.}.
But we do not know if there are any odd perfect numbers.

With a solution to the Halting Problem we could settle that question.
The program shown here searches for an odd perfect number.\footnote{It takes an
input $x$ but ignores it; in this book we have a convention that 
all programs take an input, and all give an output.}
If it finds one then it halts.
If not then it does not halt.
So giving $\computablefunction{halt\_checker}$ the index of this program
would settle whether there exists an odd perfect number.
There are many open questions 
\citetext{involving an unbounded search}{%
A computer program that solved 
the Halting Problem, if one existed, could be very slow. 
So this might not be a feasible way to settle this question.  
But at the moment we are studying what can be done in principle.} 
that would fall to this approach.
 
Before moving on, we note the appearance here of the theme of unbounded search.
It does not just appear in looking for perfect numbers.
The obvious way to test whether $\phi_e(e)\converges$
is to run a brute force computation, an unbounded
search for a stage at which the computation halts.

\subsection{General unsolvabilty}
In this subsection we will
see that the \HP{} is part of a larger unsolvability phenomenon.
We will consider a number of problems and for each
show that if we could solve it then we
could solve the \HP, and consequently 
the given problem is also unsolvable.

\begin{example} \label{ex:HaltOnThree}
Consider the problem of determining whether a given Turing machine halts 
on the input~$3$.
\begin{equation*}
  \computablefunction{halts\_on\_three\_checker}(x)=
  \begin{cases}
    1 &\case{if $\TM_x$ halts on input~$3$}  \\
    0 &\case{otherwise} 
  \end{cases}
\end{equation*}
We will show that this problem is unsolvable, that there is no
Turing machine whose input-output behavior is as above.
We will do that by showing 
that if $\computablefunction{halts\_on\_three\_checker}$ 
were a computable function then we could solve the \HP.
% \margingraphicnomag*[r]{.3\textwidth}{background/asy/hp/hp06.pdf}

Here is the idea.
Consider the program on the right below.
The middle box
simulates running $\TM_x$ on input~$x$.
If that simulation halts then the program as a whole halts
(it reads the input~$y$, ignores it, and gives a nominal output).
If that simulation does not halt then this program as a whole
does not halt, regardless of the input.
Thus, this program halts on input~$y=3$ if and only if 
$\TM_x$ halts on~$x$.
So this flowchart shows that if we were able to answer questions about 
halting on~$3$ then we could use that to answer
questions about whether $\TM_x$ halts on~$x$.
\begin{center}
  \includegraphics{background/asy/hp/hp06.pdf}
  \hspace*{2em plus 0.5fil}
  \includegraphics{background/asy/hp/hp07.pdf}
\end{center}
But we don't want to only determine whether $\TM_x$ 
halts on~$x$ for a single~$x$.
We next bring in uniformity, using the program on the left.

Assume that $\computablefunction{halts\_on\_three\_checker}$ is a computable
function and consider this.
\begin{equation*}
  \psi(x,y)=
  \begin{cases}

We closes with two comments.
The first is to reiterate that when we say that a problem is
unsolvable we mean that it is unsolvable
by a mechanism, that there  
is no Turing machine that can compute the solution to the problem.
There may well be a \citetext{function that solves it}{\autocite{wiki:ouija}}
but there is no computable function that solves it.

Out second comment is some intuition about which problems are unsolvable.
There certainly are problems that start with ``Given~$e$'' that we can solve.
Just to list one: given~$e$ decide if one instruction in $\TM_e$ is

each is about $\phi_e$, rather than about the computational details of $\TM_e$.

This takes us back to the opening of the first chapter,
where we said we were more
interested in the input-output behavior of the machines than in the
implementation details of exactly how the computation proceeds. 
In the next subsection we will expand on what this means.

\subsection{Rice's Theorem}
We have shown a number of problems to be unsolvable.
Our intuition from those examples is that
we cannot, given $e$, mechanically analyze the behavior of $\TM_e$.
We now make that intuition precise.
This is how we formalize `behavior'.

\begin{definition}
A set $\mathcal{I}$ of natural numbers is an \definend{index set} if for all 
indices~$e,\hat{e}\in\N$,
if $e\in\mathcal{I}$ and $\phi_e\samebehavior\phi_{\hat{e}}$ 
then also~$\hat{e}\in\mathcal{I}$. 
\end{definition}

\begin{example}
This set of indices
$\mathcal{I}=\set{e\in\N\suchthat \text{$\phi_e(x)=2x$ for all $x$}}$
is an index set. 
Suppose that $e\in\mathcal{I}$ and that $\hat{e}\in\N$ is such that 
$\phi_e\samebehavior \phi_{\hat{e}}$. 
Then the behavior of $\phi_{\hat{e}}$ is also to double its input: 
$\phi_{\hat{e}}(x)=2x$ for all~$x$.
Thus $\hat{e}\in\mathcal{I}$ also.
\end{example}

\begin{example}
The set
$\mathcal{J}=\set{e\in\N\suchthat
      \text{$\phi_e(x)=3x$ for all $x$, or $\phi_e(x)=x^3$ for all~$x$}}
$
is an index set.
For, suppose that $e\in\mathcal{J}$ and that  
$\phi_e\samebehavior \phi_{\hat{e}}$  where $\hat{e}\in\N$.
Because $e\in\mathcal{J}$, either 
$\phi_e(x)=3x$ for all $x$ or $\phi_e(x)=x^3$ for all~$x$.
Because $\phi_e\samebehavior \phi_{\hat{e}}$ we know that
either $\phi_e(x)=3x$ for all $x$ or $\phi_e(x)=x^3$ for all~$x$, and  
thus $\hat{e}\in\mathcal{J}$.
\end{example}

\begin{example} \label{ex:NotIndexSet}
The set $\set{e\in\N\suchthat
      \text{$\TM_e$ contains an instruction starting with $q_1$}}$ 
is not an index set.
We can easily produce two Turing machines with the same behavior,
such as giving a constant output of $0$,
and one machine contains such an instruction while the other does not.
\end{example}


\begin{theorem}[Rice's Theorem]   \label{thm:RicesThm}
Every index set that is nontrivial, that is not empty and not 
all of $\N$, is not computable.
\end{theorem}

\begin{proof}
Let $\mathcal{I}$ be an index set.
Choose some~$e_0$ so that $\phi_{e_0}(y)\uparrow$ for all~$y$;
either $e_0\in\mathcal{I}$ or $e_0\notin\mathcal{I}$.
We shall show that in the second case $\mathcal{I}$ is not computable. 
The other case is similar and is \cref{exer:OtherHalfRicesThm}.

So assume $e_0\notin\mathcal{I}$.
Since $\mathcal{I}$ is not empty there is an index~$e_1\in\mathcal{I}$.
Because $\mathcal{I}$ is an index set $\phi_{e_0}\not\simeq\phi_{e_1}$, 
so there is an input~$y$ such that $\phi_{e_1}(y)\downarrow$.

Consider the flowchart on the left.
(Note that $e_1$ is not an input, it is hard-coded into the source.)
By Church's Thesis there is a Turing machine with that behavior,
let that be $\TM_e$.
Apply the \smn{} theorem to paramatrize~$x$,
resulting in the uniformily computable 
family of functions $\phi_{s(e,x)}$ whose behavior is 
charted on the right.
\begin{center}
  \vcenteredhbox{\includegraphics{background/asy/hp/hp12.pdf}}
  \hspace{2em plus 0.5fil}
  \vcenteredhbox{\includegraphics{background/asy/hp/hp13.pdf}}
\end{center}
We've constructed the functions on the right so that if 
$\phi_x(x)\uparrow$ then $\phi_{s(e,x)}\simeq\phi_{e_0}$
and thus $s(e,x)\notin\mathcal{I}$, and so that
if $\phi_x(x)\downarrow$ then $\phi_{s(e,x)}\simeq\phi_{e_1}$
and thus $s(e,x)\in\mathcal{I}$.
Therefore being able to check whether an index $s(e,x)$
is an element of~$\mathcal{I}$
would allow us to solve the Halting Problem.
\end{proof}


\begin{example}
Show using Rice's Theorem that this problem is unsolvable: 
given $e$, decide if $\phi_e(3)\downarrow$.    

Consider the set
$
  \mathcal{I}=\set{e\in\N \suchthat \phi_e(3)\downarrow}
$.
To apply Rice's Theorem we must show that it is not empty, that 
it is not all of~$\N$, and that it is an index set.
This set is not empty because we can write a Turing machine that 
acts as the identity function $\phi(x)=x$, and where $e_0$ is the index of that 
Turing Machine then $e_0\in\mathcal{I}$.
The set is not all of $\N$ because, 
where $e_1$ is the index of a Turing Machine that never halts then
$e_1\notin\mathcal{I}$.

To show that~$\mathcal{I}$ is an index set, assume that
$e\in\mathcal{I}$ and 
that $\hat{e}\in\N$ is such that $\phi_e\simeq\phi_{\hat{e}}$.
Then $e\in\mathcal{I}$ gives that  $\phi_e(3)\downarrow$ and 
$\phi_e\simeq\phi_{\hat{e}}$ gives that
$\phi_{\hat{e}}(3)\downarrow$ also.
Hence $\hat{e}\in\mathcal{I}$, and it is an index set.  
\end{example}

\begin{example}
Show that this problem is unsolvable:
given $e$, decide if $\phi_e(x)=7$ for some~$x$.    

We will show that
$\mathcal{I}=\set{e\in\N \suchthat \text{$\phi_e(x)=7$ for some $x$}}$
is a nontrivial index set.
It is not empty because where $e_0$ is the index of a 
Turing Machine that acts as the identity function $\phi_{e_0}(x)=x$
then the input $x=7$ produces the output~$7$
so $e_0\in\mathcal{I}$.
It is not all of $\N$ because, 
where $e_1$ is the index of a Turing Machine that never halts, 
$e_i\notin\mathcal{I}$.
So this set is nontrivial.

Showing that $\mathcal{I}$ is an index set is straightforward.
Assume that $e\in\mathcal{I}$ and that $\hat{e}\in\N$ is such that
$\phi_e\samebehavior\phi_{\hat{e}}$.
Byt the first assumption, $\phi_e(x_0)=7$ for some input~$x_0$.
By the second,
$\phi_{\hat{e}}(x_0)=7$ also. 
Consequently, $\hat{e}\in\mathcal{I}$.
\end{example}

To recap, 
Rice's Theorem speaks to the behavior of the machines.
It addresses the properties of the functions
associated with the machines, rather than the properties of the machines
themselves.
The set of functions computed by programs written in C whose $100$-th character
is a `k' would not be an index set. 

We saw by a counting argument that there are unsolvable problems.
The Halting Problem shows us that there some interesting problems 
that are unsolvable.
Rice's Theorem in a sense tells us that \emph{every} interesting problem
is unsolvable.
That sense is that a problem is `interesting' if it encapsulates some behavior,
if it gives rise to 
a nontrivial index set.

\section{Computably enumerable sets}
% Required for the section on oracles, which in turn is required
% for the seciton on barriers to solving P=NP.
The natural, but naive, way to try to solve the \HP{} is to run the
calculations of $\TM_e$ on input~$e$, watching for ones that halt.
Use universailty to simulate running $\TM_0$ on input~$0$ for a few
steps, and then simulate $\TM_1$ on input~$1$ for a few steps.
Then run $\TM_0$ on~$0$ for a few more steps,
followed by $\TM_1$ on~$1$ for a few more,
and then $\TM_2$ on~$2$ for a few steps.
Keep cycling among the $\TM_e$ on~$e$ simulations,
running each for a few mopre steps before going on.
Gradually some of the calculations will halt and so
the elements of $K$ will fill in.\footnote{
  This interleaving the computations is
  \definend{dovetailing}.}
% see https://en.wikipedia.org/wiki/Recursively_enumerable_set#/media/File:Recursive_enumeration_of_all_halting_Turing_machines.gif

Of course the problem is with the complement of the set.
For those indices~$e$ where $e\notin K$, the computation never halts
and you just wait and wait.

\begin{definition}
A set is \definend{computably enumerable}, or \definend{recursively enumerable},
or \definend{c.e.}, or \definend{r.e.},
if either it is empty or it is effectively listable, that is, if it is
the set of outputs of some computable function
\definend{$W_e$=\set{k\suchthat \text{$k=\TMfcn_e(i)$ for some $i\in\N$}}}.
\end{definition}

The term `enumerable' comes from picturing a stream of output
$f(0)$, $f(1)$, $f(2)$, \ldots{} that fills out the set.

\begin{lemma}
\begin{thmparts}
\item \label{lem:SetComputableThenSetCE}
  If a set is computable then it is computably enumerable.
\item \label{lem:SetComputableIffSetAndCompCE}
  A set is computable if and only if both it and its
  complement are computably enumerable.
\end{thmparts}
\end{lemma}

\begin{proof}
For \cref{lem:SetComputableThenSetCE} let the set~$S\subseteq\N$ be computable;
we will produce an effective enumeration~$f$.
There are three cases.
If $S$ is empty then it is computably enumerable by definition.
If $S$ is finite but nonempty then where $S=\set{s_0,\ldots s_{n}}$,
a computable function whose range is~$S$ is $f(0)=s_0$, $f(1)=s_1$, \ldots
$f(n)=s_n$, and for any larger input $m>n$, let $f(m)=s_0$.
If~$S$ is infinite then let $f(0)$ be the smallest element of~$S$.
We can find
this element by trying $S(0)$, $S(1)$, \ldots.
We can try these elements effectively because~$S$ is computable.
We are sure to find one because~$S$ is infinite.
Similarly, let $f(k)$ be the $k$-th smallest element in~$S$.

For \cref{lem:SetComputableIffSetAndCompCE} first
suppose that $S$ is computable.
The prior item shows that it is computably enumerable.
And, since the fact that $S$ is computable implies that the
complement~$\setcomp{S}$ is also computable, the prior item also
gives that $\setcomp{S}$ is computably enumerable.

To finish \cref{lem:SetComputableIffSetAndCompCE}
suppose that both $S$ and $\setcomp{S}$ are computably enumerable.
If either is empty then determining whether $s\in S$ is easy.
Otherwise, suppose that $S$ is enumerated by~$f_S$ and $\setcomp{S}$ is
enumerated by $f_{\setcomp{S}}$.
Given an input~$x\in\N$,
to effectively determine which of the two sets contains~$x$,
interleave their enumerations.
That is, generate the stream
$f_{S}(0)$, $f_{\setcomp{S}}(0)$, $f_{S}(1)$, $f_{\setcomp{S}}(1)$, \ldots
This is an effective process.
The input number must eventually appear.
If $x=f_{S}(k)$ for some~$k$ then $x\in S$.
If instead $x=f_{\setcomp{S}}(k)$ then $x\in S$.
\end{proof}

\begin{lemma}
A set is computably enumerable if and only if it is the domain of a
partial computable function.
\end{lemma}

\begin{proof}
Assume first that $S$ is computably enumerable.
Then it is either empty or is the range of some partial computable function.
If it is empty then is is the domain of the partial recursive function
that converges on no input.
Otherwise~$S$ is the range of a computable function~$f$.
We will produce an effective procedure that, given an input,
halts if and only if that input is an element of~$S$.
Given $x\in\N$,
enumerate $f(0)$, $f(1)$, \ldots, and wait for~$x$ to appear.
If it does appear then halt and return some nominal value.
If it never appears then this procedure never halts.

The implication in the other direction is more involved.
Assume that $S$ is the domain of the partial computable function~$g$.
We will produce a computable function~$f$ whose range is~$S$. 
If $S$ is empty then it is computably enumerable by definition,
so assume that it is not empty and fix $\hat{s}\in S$. 

Given $n\in \N$,
we run the computation of 
$g(0)$, $g(1)$, \ldots\,$g(n)$ for $n$-many steps each.
Possibly some of these $g(k)$ computations halt.
Define $f(n)$ to be the least such~$k$ that has not already been enumerated
by~$f$, that is, it is the least $k$ so $g(k)$ halts within~$n$ steps and such
that $k\notin\set{f(0),f(1),\ldots f(n-1)}$.
If no such $k$ exists then define $f(n)=\hat{s}$.

To see that every element $s\in S$ is eventually enumerated by~$f$, note that
$g(s)$ must converge in some number~$n_s$ of steps.
At that point the number~$s$ is queued for output, in the sense that
it will be enumerated by~$f$ as, at most, $f(n_s+s)$. 
\end{proof}

The prior argument's technique of interleaving the computations
is known as \definend{dovetailing}.

\begin{lemma}
The \HP{} set $K$ is computably enumerable.
Its complement $\setcomp{K}$ is not.
\end{lemma}

\begin{proof}
The set $K$ is the domain of the partial computable function~$f$ where
$f(e)$ is computed by running the Turing machine~$\TM_e$ on input~$e$.
But the complement~$\setcomp{K}$ is not computably enumerable, since that
would imply that $K$ is computable, while the unsolvability of the
\HP{} shows it is not.
\end{proof}

\section{Oracles} \label{sec:Oracles}
The \HP{} is unsolvable.
Is it the hardest problem or are there ones that are even harder?

\margingraphic{0.2\textwidth}{background/delphi.png}{\label{fig:yogi}\href{https://en.wikipedia.org/wiki/Pythia}{The oracle at Delphi}}
What does it mean to say that one problem is harder than another?
When we considered the problem of deciding whether
a Turing machine halts on input~$3$,
we proved that if we could solve it then we could solve \HP.
% We did the same for many other problems, such as the problem of whether
% the given Turing machine ever outputs-$7$.
That is, in the proofs in that section
we showed that these problems are at least as hard as the \HP.
So we have an idea of relative computability,
of `if we could solve problem~$P$ then we could
solve problem~$Q$'.

Of course, under Church's Thesis we interpret our proof of the \HP{} to
say that our computing mechanisms cannot answer questions about
membership in~$K$. 
We must instead look for the answers to be supplied by some external source.
Consequently, we posit that to the Turing machine CPU we can attach a device,
an \definend{oracle},
that acts as the characteristic function of a set. 
To see what could be computed if only we could solve
the \HP{} we can attach a $K$-oracle,
answering questions of the form,
``Is $x\in K$; does $\TMfcn_{x}(x)\converges$?''\footnote{%
  We treat the oracle as a black box,
  meaning that we don't open it up to see how it works\Dash that would
  let out the \citetext{magic smoke}{See \autocite{wiki:MagicSmoke}.}.}
\begin{center}
  \includegraphics{background/asy/machine/machine00.pdf}
\end{center}

One way to define an oracle computation
extending that of Turing machines is:~to the action
symbols \str{L} and~\str{R} we add one more, \str{O}.
When this symbol applies, where the I/O head is under the
leftmost \str{1} of a sequence of $n+1$-many \str{1}'s,
that sequence is replaced
by either a single~\str{1} followed by $n$-many \str{0}'s if $n\in A$,
or entirely by $n+1$-many \str{0}'s if $n\notin A$.

For a full treatment see \autocite{Rogers}.
In this sectinon, instead of working with the details of the
definition we will use Church's Thesis and
consider introducing into a programming language 
a boolean function \lstinline!oracle(x)!, as here.
\begin{lstlisting}
(if oracle(x)
    (display "It is a member of the set.")
    (display "It is not a member of the set."))
\end{lstlisting}
This is a \definend{computation relative to the oracle}.
    
The above code snippet highlights that programs in this extended language do not
change if we change the oracle\Dash
if we have an $A$ oracle box plugged in, then unplug it and replace
it with a~$B$ oracle box, 
the source is unchanged.
(Of course, the outcome of the computation may differ.)
Thus, as when we defined computation in the first chapter,
we have a family of programs.
They are just like programs in that first chapter except now they
can contain the \lstinline{oracle} call.
Each program is a string, so there are countably many.

To specify an outcome of a relative computation, in addition to specifying
which program we are using by giving its index~$e$, and which inputs
we are we giving it, need to include
an oracle set~$A$, leaving us with the notation \definend{$\TM^A_e$}.
The associated function,
\definend{the function computed relative to $A$}, is denoted
\definend{$\TMfcn_e^A$}.

\begin{definition}
If the function computed relative to $A$ is the characteristic function
of a set~$B$ then we say that \definend{$B$ is $A$-computable} or that
$B$ is \definend{Turing reducible} to $A$,
denoted \definend{$B\leq_T A$}.\footnotemark[1]
\end{definition}\footnotetext{The terminology ``$B$ is reducible to $A$''
  can be confusing.
  The idea is that we can solve the problem of~$B$ by
  instead solving~$A$.
  For instance, we can reduce solving the \HP{} to solving
  halts-on-$3$ problem.}

Think of the set $B$ as being simpler, or at least no harder, than the set~$A$.

\begin{theorem}
\begin{thmparts}
\item A set is computable if and only if it is computable
relative to the empty set, or to any computable set.
\item A set $A$ is computable from $B$
\item \textsc{(Reflexivity)} Every set is computable from itself, $A\leq_T A$.
\item \textsc{(Transitivity)} If $A\leq_T B$ and $B\leq_T C$ then $A\leq_T C$.
\end{thmparts}
\end{theorem}

\begin{proof}
For the first, a set is computable if its characteristic function is computable.
Clearly if the characteristic function is computable without reference to an
oracle, then it can be computed by an oracle machine, just by ignoring the
oracle.
For the other direction, suppose a characteristic function can be computed
by reference to the empty set oracle (or any other computable oracle).
Then it can be computed without reference to an oracle, just by replacing
oracle calls with computations.

The second item is clear.
For the third, suppose that $\TM_e^B$ computes the characteristic
function of~$A$ and that $\TM_{\hat{e}}^C$ computes the characteristic function
of~$B$.
Then in the computation of $A$ from the $B$~oracle we can replace the
oracle calls to those calling $\TM_{\hat{e}}^C$.
The result is a routine that computes the characteristic function of $A$
directly from a $C$~oracle.
\end{proof}

\begin{example}
The halts on~$3$ problem asks for a program that acts as the
characteristic function of the set
$A=\set{e\suchthat \text{$\TM_e$ halts on~$3$}}$.
We will show that $K\leq_T A$.

This is a reprise of \cref{ex:HaltOnThree}.
Consider the function $\map{\psi}{\N^2}{N}$
that returns $0$ if $\phi_x(x)\converges$ and that diverges otherwise.
By Church's Thesis
there is a Turing machine whose input-output behavior is $\psi$.
Let that machine have index~$e$, so that $\psi=\phi_e$.
Apply the \smn{} theorem to parametrize~$x$, giving $\phi_{s(e,x)}$.
Observe that $\phi_x(x)\converges$ if and only if
$A(s(e,x))=1$.
That computes $K$ from an $A$~oracle.
\end{example}

Consider again the statement of the \HP,
to determine the characteristic function of the set
$\set{e\suchthat \text{$\TM_e$ halts on input~$e$}}$.
That statement may seem odd.
Surely the more natural question is whether $\TM_e$ halts on input~$x$?

\begin{definition}
  $\definend{K_0}=\set{\sequence{e,x} \suchthat \text{$\TM_e$ halts on input~$x$}}$
\end{definition}

We will argue that the two problems are computationally equivalent, 
are inter-solvable, meaning that if you can solve the one then
you can solve the other, and so the choice of problem is a 
matter of convenience, and convention.
% \footnote{%  
%   For the definition we go with $K$ 
%   because it is the standard usage and because it has some technical advantages,
%   including that it falls out of the diagonalization development done
%   at the start of this subsection.}

\begin{definition}
Two sets $A,B$ are \definend{$T$-equivalent, $A\equiv_T B$} if $A\leq_T B$
and $B\leq_T A$.
For any set~$A$, the collection of sets $T$-equivalent to $A$ is the
\definend{Turing degree} of~$A$.
We denote the Turing degree of~$A$ using boldface, \definend{$\textbf{a}$}.
\end{definition}

\begin{lemma}
The two sets $K$ and $K_0$ are inter-computable: $K\equiv_T K_0$.
\end{lemma}

\begin{proof}
For the first, suppose that we have access to a $K_0$-oracle.
Since it can tell us whether $\TM_e$ halts on~$x$ for any input~$x$,
it can clearly tell us whether $\TM_e$ halts on~$e$.

For the other half, suppose that we have access to a $K$~oracle and are
given the pair $e,x\in\N^2$.
We want to compute whether $\TM_e$ halts on input~$x$.
Consider the program on the left below.
By Church's Thesis there is a Turing machine implementing

\begin{theorem}
The Relativized \HP{},
the problem of computing the characteristic function of 
$K^K=\set{x\suchthat \TMfcn_x(x)\converges}$,
is not computable from a $K$ oracle: there is no index~$e\in\N$
so that $\TMfcn_e^K=K^K$.
\end{theorem}

\begin{proof}
Assume otherwise, that there is a mechanical computation relative to a
$K$~oracle with this behavior.
\begin{equation*}
  K^K(e)=
  \begin{cases}
  1  &\case{if $\TMfcn^K_e(e)\converges$}  \\
  0  &\case{if $\TMfcn^K_e(e)\diverges$} 
  \end{cases}
  \tag{$*$}
\end{equation*}
Then the function below is also computable relative to a $K$~oracle.

it uses the above function for the branch.

    \end{cases}

$f(x)=\TMfcn^K_{\hat{e}}(x)$ for all~$x$.

Now feed $f$ its own index\Dash consider
$f(\hat{e})=\TMfcn^K_{\hat{e}}(\hat{e})$.
If it diverges then the first clause in the definition of~$f$

which contradicts that $f$~diverges.
If it converges then $f$'s second clause

We constructed~$f$ by assuming only that

\section{Philosophical impact}
The \HP{} and related results are about limits.
Given Church's Thesis, they say that there are things that we can never do.
To understand their impact, in the intellectual world
outside mathematics as well as inside,
we must place them in their historical setting.

\margingraphic{0.35\textwidth}{background/crystalpalace.jpg}{\label{fig:crystalpalace}\href{https://upload.wikimedia.org/wikipedia/commons/6/61/Crystal_Palace_-_Queen_Victoria_opens_the_Great_Exhibition.jpg}{Queen Victoria opens the Great Exhibition of the Works of Industry of All Nations, 1851}}
With 
\citetext{Napoleon's downfall in the early 1800's}{See 
\autocite{wiki:AubreyMaturin}.}, 
many people in Europe felt a swing back to
a sense of order and optimism, fueled by progress.\footnote{These
statements are in the context of European general intellectual culture,
which is the context in which early Theory of Computation results
appeared and is the context in which this book is written.
A broader view is outside our scope.}
For example, in England, Queen Victoria's reign from 1837 to~1901
seemed to many commentators to be an extented 
\citetext{period of prosperity and peace}{See \autocite{wiki:PaxBritannica}.}.
Across wider Europe, people perceived that the natural world 
was being tamed with science and
engineering:~witness the introduction of steam railways in 1825, 
the opening of the Suez Canal in 1869, the invention of the electric light in
1879.\footnote{This is not to  % , and construction of the Eiffel Tower in 1889
say that this perception is without exception, is sensible, or is justified.
Disease and poverty were rampant, colonialism and imperialism 
were ruining the lives of millions, 
for much of the period the horrors of industrial slavery in the US south
went unchecked, and Europe was hardly an oasis of calm and
refinement, with for instance the revolutions of 1848. 
Nontheless the zeitgeist included a sense of progress, of winning.}  

In science this same feeling was expressed by 
\citetext{A~A~Michelson, who wrote in 1899,
``The more important fundamental laws and facts of physical science have 
all been discovered, and these are now so firmly established that the 
possibility of their ever being supplanted in consequence of new 
discoveries is exceedingly remote.''}{Michaelson was not a minor figure
who was expressing a minority view.
From 1901 to~1903 he was president of the American Physical Society. 
In 1910--1911 he was president of the American Association for the 
Advancement of Science and from 1923--1927 he was president of the 
National Academy of Sciences. In 1907 he received the Copley Medal from 
the Royal Society in London, and the Nobel Prize.  
He is 
still well-known today for the Michelson–Morley experiment that
tried to find the presence of aether, the hypothesized medium through with 
light waves travel.}
Many researchers felt this way, 
that the nature of the universe was largely understood
and what remained was only to work out the messier details.

\margingraphic[l]{0.2\textwidth}{background/hp/hilbert1932.jpg}{\label{fig:hilbert1932}\href{https://en.wikipedia.org/wiki/Ignoramus_et_ignorabimus}{D~Hilbert 1862--1943}}
In Mathematics, the view from the 1800's was typified in Hilbert's 1930 
address,\footnote{Hilbert grew up in the 1800's and here is speaking in reaction to the changes; this is from his retirement address.}
``We must not believe those, who today, with philosophical bearing and 
deliberative tone, prophesy the fall of culture and accept the 
\textit{ignorabimus}. 
For us there is no \textit{ignorabimus}, and in my opinion none whatever 
in natural science. 
In opposition to the foolish ignorabimus our slogan shall be:~Wir 
m\"ussen wissen — wir werden wissen.'' 
(The final phrase translates as, ``We must know\Dash we will know.''
`\textit{Ignorabimus}' means `that which we must be forever ignorant of'
or `that thing we will never fully penetrate'.)
Of course there was a range of opinion but the general sense was that
people had done so much and were moving steadily forward that
no doubt any question would be settled eventually.

But with the new century, with the 1900's, that sense changed.

\margingraphic{0.3\textwidth}{background/wwi.jpg}{\label{fig:crystalpalace}\href{https://upload.wikimedia.org/wikipedia/commons/6/61/Crystal_Palace_-_Queen_Victoria_opens_the_Great_Exhibition.jpg}{World War I German dead in a trench}}
Exhibit~A is this picture.
Although the terrible effects of the modern mastery 
of mechanisms on warfare was apparent by the US Civil War,
it was not generally understood until World War~I, 1914-1918.

With universal conscription, probably the guys in this picture 
did not want to be here.
They were killed by a guy who probably also did not want to be here,

If you were at those coordinates 
then it didn't matter how brave you were, or how strong, or

All that stuff they told you about your folk, and honor, and god,

The general sense became that Pandora's box had opened,
that things were out of control, that we did not live in
an ordered world. 

In science, Michaelson's assertion that 
physics was essentially a solved probblem
was destroyed by the discovery of radiation in 1896.
This changed everything by bringing in quantum theory, 
that places at the
heart of its approach that there are events that are completely random,

With Albert Einstein we see most 
directly the shift in wider intellectual culture,
away from a sense of unlimited progress.
After experiments during a solar eclipse in 1919 provided strong support for
his theories, Einstein became an overnight celebrity 
(``Einstein Theory Triumphs'' was the headline in The New York Times).
He was seen by the public, or at least by the reading public, as having 
changed our view of the universe from
a Newtonian clockwork to one where 
\citetext{``everything is relative.''}{%

His work showed that the universe has absolute limits and that
everyday 
\margingraphic{0.3\textwidth}{background/hp/thepersistenceofmemory.jpg}{\label{fig:persistenceofmemory}\href{http://www.newyorker.com/magazine/2005/02/28/time-bandits-2}{Salvadore Dali's 1931 \textit{Persistence of Memory}.

perceptions break down: nothing
can travel faster than light,  
time bends, and even the commonsense idea of 
two things happening at the same instant falls apart.  

In the general culture there were many reflections 
of this sense of loss of certainty.
For example, 
the generation of writers and artists who came of age in World War~I 
became known as the  Lost Generation.
In literature they expressed their experience through themes of alienation, 
isolation, and dismay at the corruption they saw around them.
Famous writers in this group included 
Eliot, Fitzgerald, Hemingway, Pound, and Stein.
In music, composers such as Debussy, Mahler, and Strauss broke with the
traditional expressive forms, in ways that were often hard for listeners
to understand\Dash Stravinsky's \textit{Rite of Spring} caused a 
near riot at its premiere in 1913. 
As for art, the painting here dramatically shows that visual artists 
also picked up on these themes.

Much the same inversion of the standing order as Einstein represented
happened in mathematics in 1930 with K~G\"odel's announcement of the
First Incompleteness Theorem.\footnote{This happened at the same meeting
as the one where Hilbert gave his retirement address.} 
The Incompleteness Theorem says that
in any (sufficiently strong) formal system there are  
straightforward statements that, while true in that system, 
cannot be proved in that system.
We say more elsewhere, \cref{extra:Godel}, but 
even without elaboration the theorem is clearly about what cannot be done\Dash
there are true things, correct things, and
we shall never prove them.
This statement of basic limits
seemed to many observers to be especially striking in the field of 
mathematics.

G\"odel's Theorem is closely related to the \HP.
It and other uncomputability results are in the same vein. 
To people at the time these results were deeply shocking,
revolutionary.
Today we work in an intellectual culture that has absorbed this shock,
that is part of the background of what we all have come to expect,
but we should recognize them as our bedrock.

\extra{Busy Beaver}
% See also: https://johncarlosbaez.wordpress.com/2016/05/21/the-busy-beaver-game/
We compute things all the time so noncomputability is 
counterintuitive.
Here we see one way that a function can fail to be computable.  

Consider this attempt to solve the Halting Problem:
Turing machines are made of four-tuples.
For any~$n\in\N$ the set $T_n=\setbuilder{e}{\sizeof{\TM_e}\leq n}$ 
of machines with $n$~many tuples or fewer is finite.
For some members of the set
$\TM_e(e)$ halts and for some it does not, but because the set if finite,
certainly the information
on which of the set's member machines halt must also be finite.
We can compute finite sets.
So to solve the Halting Problem, given a Turing Machine~$\TM$, 
find how many four-tuples it has,
compute the associated finite halting information set, 
and then we know whether $\TM$ halts.
What's the problem with that?

The problem is uniformity.
We can compute any one of the finite sets.
But there is no single computable function that does them all\Dash
no computable function that accepts inputs~$\sequence{n,e}$ and that 
outputs~$1$ if there is a $n$-tuple machine such that $\TM_e(e)$ halts,
or~$0$ otherwise.

% \newenvironment{hangingpar}[1]
%   {\begin{list}
%           {}
%           {\setlength{\itemindent}{-#1}%%'
%            \setlength{\leftmargin}{#1}%%'
%            \setlength{\itemsep}{0pt}%%'
%            \setlength{\parsep}{\parskip}%%'
%            \setlength{\topsep}{\parskip}%%'
%            }
%     \setlength{\parindent}{-#1}%%
%     \item[]
%   }
%   {\end{list}}

The natural uniform attack along these lines is to start all of the 
$n$-tuple machines,
all the $\TM_e(e)$ for $e\in T_n$
and run them in a breadth-first way until no more of them will ever converge.
So consider this function  \map{D}{\N}{\N}.
\begin{equation*}
  D(n)= \text{\begin{minipage}[t]{0.7\textwidth}
                 \begin{hangingpar}
                   minimal number of steps 
                   after which all of the $n$-instruction machines 
                   that will ever converge have done so
                 \end{hangingpar}
               \end{minipage}} 
\end{equation*}

We can prove that $D$ is not computable.
Assume otherwise.
Then to compute whether $\TM_e$ halts on input~$e$, 
find how many instructions $\TM_e$ has, compute $D(n)$,
and run $\TM_{e}(e)$ for $D(n)$-many steps.
If it has not halted by then, it never will.
Of course, this contradicts the unsolvability of the \HP.

So far this just seems like another uncomputable function; why is it
especially enlightening? 
Observe that if a function $\hat{D}$ has values larger than $D$\Dash
if $\hat{D}(n)\geq D(n)$ for all sufficiently large~$n$\Dash
then $\hat{D}$ is also not computable.
This tells us that one way that functions could fail to be computable is that 
they could grow too fast.
This is not the only way that a function can fail to be computable, but it helps
to answer the ``Why not?'' question.

\subsection{Busy Beaver is unsolvable}
Why isn't $\Sigma$ computable?
The obvious thing is to do a breadth-first search:~there 
are finitely many $n$-state machines,
start them all on a blank tape,
and await developments. 

That won't work because some of the machines won't halt.
At any moment you have some machines that have halted and you can see
how many $1$'s are on each such tape, so you know the longest so far.
But as to the not-yet-halted ones, who knows?
You can by-hand see that this one or that one will never halt
and so you can figure out the answer for $n=1$ or~$n=2$.
But there is no algorithm to decide the question for an arbitrary
number of states. 

\begin{theorem}[Rado, 1962]
The function $\Sigma$ is not computable.  
\end{theorem}

\begin{proof}
Suppose that $\map{f}{\N}{\N}$ is computable.
We will show that $\Sigma$ is not equal to~$f$.
Specifically, we will show that $\Sigma(n)>f(n)$ for infinitely many~$n$.

First note that there is a Turing Machine $\TM_j$
having $j$~many states that writes $j$-many $1$'s to a blank tape.
For instance, here is $\TM_4$.
% \begin{center}
%   \includegraphics{asy/four_ones.pdf}
% \end{center}

Second we define a way to combine Turing machines:~we 
make the \textsc{Halt} state
of the first machine the start state of the second.
% \begin{center}
%   \vcenteredhbox{\includegraphics[width=.4\textwidth]{asy/join_tms.pdf}}
%   \hspace{1.5em}to\hspace{1.5em}
%   \vcenteredhbox{\includegraphics[width=.4\textwidth]{asy/join_tms_after.pdf}}
% \end{center}

Consider this function.
\begin{equation*}
  F(m) % &= \sum_{0\leq i\leq m} f(i)+i^2            \\
       = (f(0)+0^2)+(f(1)+1^2)+(f(2)+2^2)+\cdots+(f(m)+m^2)
\end{equation*}
If $0<m$ then $f(m)<F(m)$,
and $m^2\leq F(m)$,
and $F(m)<F(m+1)$.
This function is intuitively computable so Church's Thesis says there is a 
Turing machine $\TM_F$ that computes it.
Let it have $n_F$~many states.

Consider the Turing machine $\TM$
which performs $\TM_j$ and then follows it with 
$\TM_F$, and in turn follows that with 
$\TM_F$. 
If started on a blank tape this machine will first produce $j$-many $1$'s,
then produce $F(j)$-many $1$'s, and finally will leave the tape with 
$F(F(j))$-many $1$'s.
Thus its productivity is 
$F(F(j))$, and it has $j+2n_F$ many states.

Finally, consider the $j+2n_F$-state Busy Beaver machine.
\begin{equation*}
  F(F(j))\leq \Sigma(j+2n_F)
\end{equation*}
Because $n_F$ is constant (it is the number of states in
the machine $\TM_F$), for large $j$ we have
$j+2n_F\leq j^2< F(j)$.
Since $F$ is strictly increasing, $F(j+2n_F)<F(F(j))$.
Combining gives this.
\begin{equation*}
   f(j+2n_F) <
   F(j+2n_F) <
   F(F(j))
   \leq \Sigma(j+2n_F)
\end{equation*}
Since $f$ is any computable function, $\Sigma$ is not computable.
\end{proof}

So one way for a function to fail to be computable is if it grows faster than
any computable function.
(This is not the only way.  
There are functions that grow slower than some computable function but
are nonetheless not computable.)
