$f$'s growth rate is less than or equal to $g$'s rate.

    \item Although Turing machines are discrete devices, we find the

    \item

    \item

\end{itemize}

\begin{frame}{The Hardy Hierarchy}
\ExecuteMetaData[\catchfilefn]{lem:PolySlowerThanExp}

\begin{example}
This shows that $f(x)=\lg(x)=\log_2(x)$ is $\bigOh(g)$ where
$g$~is the polynomial $g(x)=x^2$.
\begin{equation*}
  \lim_{x\to\infty}\frac{1/(x\cdot \ln(2))}{2x}
  =\lim_{x\to\infty}\frac{1}{x^2\cdot 2\ln(2)}

\begin{example}

 \qquad

  =0
\end{equation*}
\end{example}

\begin{frame}{Representations}
We shall assume that all of the input and output for our
algorithms is in some reasonably 
efficient representation in bit strings.

Thus, we shall understand ``given two numbers $n_0,n_1\in\N$'' to mean
`given the bit string representation of two numbers'.
And 
we shall take ``let $\mathcal{G}$ be a graph'' to mean
`given a reasonably efficient representation of a graph~$\mathcal{G}$'.

Having observed that, we will from now on usually ignore it.
\end{frame}


\begin{frame}{Types of problems}
\begin{itemize}
\item A \alert{function problem}.
   asks that the algorithm have a single output for each input.
\item An \alert{optimization problem}, which look for the 
  best solution according to some metric.
\item With a \alert{search problem}, while there may be many
  solutions in the search space, we stop when we have found any one.
\item A \definend{decision problem} has a `Yes' or `No' answer.
\item Often a decision problem is expressed as a
   \alert{language recognition problem},
   where we are given some language and asked for an algorithm to
   decide if an input is a member of that language.
\end{itemize}
\end{frame}


\begin{frame}{Problems, classes}
In this chapter, usually \alert{problem}
means a decision problem for a language.
Often, we will recast problem statements into language decision terms.

\begin{example}
The Subset Sum problem is `given a set~$S$ of numbers 
and a target number~$T$, decide if a subset adds to the target'.
We can recast it as the problem of deciding membership in this language.
\begin{equation*}
  \lang=\set{\sequence{S,t}\suchthat \text{A subset of $S$ adds to~$t$}}
       =\set{\sequence{\set{19,21,52,106},40},\ldots}
\end{equation*}
\end{example}

\begin{example}
Consider the problem `given a graph and two vertices in the graph, decide if
there is a path between the two'.
Recast it as a decision problem for this language.
\begin{equation*}
  \lang=\set{\sequence{\mathcal{G},v,\hat{v}}\suchthat
    \text{there is a path in~$\mathcal{G}$ between the vertices $v$ and~$\hat{v}$}}
\end{equation*}
\end{example}

\begin{example}
To recast the Shortest Path problem, set a bound~$B\in\N$ and consider this
language.
\begin{equation*}
  \lang_B=\set{\sequence{\mathcal{G},v,\hat{v}}\suchthat
               \text{there is a path between the vertices of length bounded by~$B$}}
\end{equation*}
To find the shortest path, see if there is a $B=1$ path, then see if there
is a $B=2$ path, etc. 
\end{example}

\end{frame}

\begin{frame}{Effect of the model of computation}
Different models of computation work at different speeds.
In particular, we perceive that Turing machines are slow;
does that affect which problems go in which classes?

Close analysis shows that
Turing machines are typically slower than other natural models
by a factor of $n^2$ or $n^3$.
(We take a model to be `natural' if it
  was not invented just to be a counterexample to this.)
Thus, if we have a problem for which there is a
$\bigOh(n)$ algorithm on
another model then when translated to a Turing machine
algorithm it may be $\bigOh(n^4)$.
An extended version of Church's thesis posits that any
reasonable model of computation can be simulated on a
(probabilistic) Turing machine in polytime.
This thesis controversial and does not enjoy anything like
the support of the original.
But under it a problem that falls in the class~$\P$ using Turing machines
also falls there using other natural models.

\pause
\begin{remark}  
  There in the air is a possible exception to the extended thesis. 
  Under the Quantum Computing model
  there are several problems with polytime solutions,
  including integer factorization,
  for which we do not know of any polytime solution in a natural
  non-quantum model.
  Whether quantum computers will ever be practical physical devices is not
  at this moment perfectly clear but scientists and engineers seem to be making
  progress developing them.
\end{remark}
\end{frame}


\begin{frame}{Naturalness of the class $\P$}
There are several reasons why the class~$\P$ is natural to
study.

\begin{itemize}
\item It is invariant under the choice of
computing model.

If a problem is in $P$ based on any familiar model
including Turing machines, Integer RAM, and Scheme programs, then
it is in~$P$ for all of them.

\item It has a number of appealing closure properties.

\ExecuteMetaData[\catchfilefn]{discussion:PClosure}
\end{itemize}
\end{frame}

\section{Nondeterministic polynomial time}

\begin{frame}{$\NP$}
Recall that a machine is nondeterminstic if
from a present configuration and input
it may pass to a next configuration where the number of next states
is zero, or one, or more.

Recall also that we have two models of how these devices operate.
In the first, the machine's computation history is a tree and it
simultaneously computes all branches.
That is, we picture the machine as unboundedly parallel.

In the second model the machine guesses which next state to follow,
or is told which next state to follow by a demon, and
then deterministically computes a check of that branch of the computation tree.
With the first model we say an input string is accepted if one of the 
branchs on the tree is an accepting branch.

\pause
With the first model we say an input string is accepted if one of the 
branchs on the tree is an accepting branch.
With the second model we say the input
is accepted if there is a sequences of guesses that the machine could
make, or if there exists a sequence of
branching hints that the demon could produce,
that leads to an accepting state.
With those definitions, the two models are logically equivalent in that
they accept the same languages.
\end{frame}

\begin{frame}
\begin{example}
The Vertex-to-vertex Path problem
takes as input a graph and two vertices, and accepts the triple if
there is a path between the vertices.
\begin{equation*}
  \lang=\set{\sequence{\mathcal{G},v,\hat{v}}\suchthat
              \text{there is a path in $\mathcal{G}$ from $v$ to $\hat{v}$}}
\end{equation*}
This problem is in $\NP$.
The witness~$\omega$ is the path.
We can write a verifier~$\TM$ that accepts a triple~$\sigma$ and a 
witness~$\omega$, and tries to verify that the path lies in the graph between
the two vertices.
If there is such a path then there is a pair $\sequence{\sigma,\omega}$ for
which $\TM$ can accept.
If there is no such path then there is no such pair. 
\end{example}

\pause
\begin{example}
\alert{Linear programming} is to optimize some objective function
$f(x_0,\ldots x_n)=a_0x_0+\cdots+a_nx_n$ 
subject to a list~$C$ of constraints of the form
$b_{i,0}x_0+\cdots+b_{i,n}x_n\leq d_i$ and $x_i\geq 0$.
To make this a language decision problem, recast it using a bound.
\begin{equation*}
  \lang_B=\set{\sequence{f,C}\suchthat
    \text{some $\sequence{x_0,\ldots x_n}$ satisfies the constraints and~$f(x_0,\ldots x_n)\geq B$}}
\end{equation*}
The witness is $\omega=\sequence{x_0,\ldots x_n}$.
We can write a verifier~$\TM$ that takes in a problem~$\sigma$ and a
purported witness~$\omega$, and checks whether the seequence satisfies the
constraints of the problem and also makes the objective function large.
If there is such a sequence then $\TM$ can verify it, in polytime.
If there is no such sequence then $\TM$ can never succeed in verifying.  
\end{example}

\pause
\begin{example}
The problem of \alert{$3$-Coloring} takes a graph as input
and decides if it can be colored with at most $3$~colors.
For a witness~$\omega$ use purported a $3$-coloring.
Verifying that a graph is $3$-colored 
can be done in time polynomial in the size of the graph.
\end{example}
\end{frame}

\section{Problem reduction}

\begin{frame}{Introduction}
Recall the Vertex-to-vertex Path problem:~given a graph and two vertices,
decide if there is a path between them.
Recall also the Shortest Path problem:~given a weighted graph and two
vertices, find the shortest path between them.

These two are obviously related.
In particular, if you can find the shortest path then you can find
whether there is a path at all, no?

\pause
To make this idea precise recast these as language decision problems
\begin{align*}
  \lang_1 &=\set{\sequence{\mathcal{G},v_0,v_1}\suchthat
               \text{there is a path from $v_0$ to $v_1$ in $\mathcal{G}$}} \\
  \lang_B &=\set{\sequence{\mathcal{G},v_0,v_1}\suchthat
               \text{there is a path from $v_0$ to $v_1$ shorter than length~$B$}}
\end{align*}
(with the second we are applying the standard bound technique using 
the parameter~$B\in\N$).

There is a type issue because
the Shortest Path problem applies to weighted graphs.
But we can convert an unweighted graph to a weighted one by giving each edge 
a weight of~$1$. 
\end{frame}

\begin{frame}
Suppose that you could solve the Shortest Path problem.
Perhaps you have a library routine \str{SolveShortestPath}.

\begin{frame}{?$\P=\NP$?}
Every deterministic Turing machine is trivially a nondeterministic machine,
and so $\P\subseteq\NP$.
What about the other direction:~can unbounded parallelism bring problems
from super-polynomial to polynomial?

The short answer is that no one knows.
We do not know which of these two is right.
