% ------------------------------------------------------
\begin{frame}
  \frametitle{Introduction}

What can be done?

\pause
In 1928, D~Hibert and his student W~Ackermann proposed the
\textit{Entscheidungsproblem},
which asks for a definite procedure
(what we today call an algorithm) that decides, from an input mathematical
statement, whether that statement is true or false.

Being interested in what is true or false requires no
further explanation.
But why the definite procedure?

\pause
In Mathematics and Computer Science we take Euclid's development a paradigm.
The theorems follow from the axioms in a definite way: you can check,
mechanically, each step of the proofs.
So we start by defining a mechanical computation.
\end{frame}


\begin{frame}
  \frametitle{Turing machine}
A~Turing's approach to the \textit{Entscheidungsproblem} was to 
describe a mechanism that computes.
He imagined a clerk doing by-hand multiplication
with a sheet of paper that gradually becomes covered with columns of
numbers.
With that image he described a number of principles that a 
computing machine must satisfy.

\section{Church's Thesis}

\begin{frame}{Statement of Church's Thesis}
% \ExecuteMetaData[\catchfilefn]{ChurchsThesis}
\framebox{\alert{\parbox{0.95\textwidth}{The set of things that can be computed 
by a discrete and deterministic mechanism 
is the same as the set of things that can be computed by
a Turing machine.}}}
 
  Some authors call this the Church-Turing Thesis.  
  Here we figure that because Turing has the machine, 
  we can give Church sole possesion of the thesis.
\end{frame}

\begin{frame}{Evidence}
\begin{description}[xxx]  % optional argument sets width of indent
\item[Coverage]
Everything that people think of as intuitively computable has proven to
be computable on a Turing machine.
\item[Convergence]
There have been many models of computation proposed, and all 
compute the same set of things, the set of things computed by
Turing machines.
\item[Consistency]
The details of the definition, including the number of tapes or tape
heads, the number of symbols available, the number of states, all
don't change the collection of things computed.
(This includes the condidition of determinism.)
\item[Clarity]
Turing's analysis is persuasive of itself.
\end{description}
\end{frame}

\begin{frame}{An empirical question?}
As yet, there is no persuasive evidence of physically possible
systems that allow you to compute things that a Turing machine
cannot compute.

We shall take proposals involving wormholes, black hole event horizons,
etc., 
as not yet persuasive.

In particular, note that quantum computers cannot compute things
that a Turing machine cannot do.
We expect that they will run faster, but are not more capable.  
\end{frame}

\begin{frame}{Arguments by Church's Thesis}
Church's Thesis equates `computable' with `computable on a Turing machine'.
We will use it in two ways.
\begin{enumerate}
\item It gives our results a larger, philosophical, importance.
When we produce a result \textit{No Turing machine can \ldots{}}, 
Church's Thesis changes it to \textit{This task cannot be done: \ldots{}}
\item To prove a result about Turing machines we will 
argue using intuitive computability.
For instance, consider the problem of whether this function is computable:~it 
inputs a number and
returns~$1$ when it is a prime, and~$0$ otherwise.
To show that can be computed by a Turing machine, we will not exhibit
such a machine.
We will instead argue that the function is intuitively computable, and invoke
Church's Thesis.

This is potentially dangerous, but we have so much experience with computation
that our intuition is quite good, and for us there is more of a danger
of being overwhelmed by detail than of being too vague. 
\end{enumerate}
\end{frame}

\begin{example}
A \alert{Carmichael number}~$n$ is defined by:~for all $b\in\set{1,2,\ldots,n}$
relatively prime to~$n$,
the number $b^{n-1}$ leaves a remainder of~$1$ on division by~$n$.
The first such number is~$561$.
The function
\begin{equation*}
  g(n)=
  \begin{cases}
    1  &\case{if $n$ is a Carmichael number}  \\
    0  &\case{otherwise}
  \end{cases}
\end{equation*}
is primitive recursive.
Here we define the Carmichael number function
by $\mu$-recursion.
\begin{equation*}
  C(n)=
  \begin{cases}
    561  &\case{if $n=0$}           \\
    \least y\,\big[ \text{$y>f(n-1)$ and $1-g(y)=0$} \big]
         &\case{otherwise}
    \end{cases}
\end{equation*}
\end{example}
\end{frame}



\begin{frame}
\ExecuteMetaData[\catchfilefn]{def:GeneralRecursive}

collection of functions computed by some Turing machine, which we
call the `computable functions'.
\end{frame}
